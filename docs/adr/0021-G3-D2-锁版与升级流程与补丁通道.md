## 问题

G3 要把样式与布局引擎（`stylo / stylo_taffy / taffy / parley / selectors / skrifa / fontique`）接进
`layout-backend`。需拍板：版本策略取「**精确锁定**」还是「**跟随最新**」；`Cargo.lock` 入库口径；
升级流程；是否保留 vendor 补丁通道。

## 讨论要点

| 维度 | 评审 A | 评审 B | 主理人裁决 |
|---|---|---|---|
| 版本组合与 t2_4 `Cargo.lock` 实况 | **完全一致**（逐条复核，附录 E1），不反驳 | 复核一致 | **采纳** |
| `stylo_taffy` 内部钉 `stylo ^0.20.0` ⇒ 写 0.22 双版本并存 | 机制**成立**（附录 E2） | 同 | **采纳** |
| 「上游 0.22 / parley 0.12」数字 | **不可复核**（本地 registry 无该版本；AGENTS.md 禁联网） | 同 | **采纳：删除不可复核数字**（G3-B4） |
| 「同源锁定树实测」措辞 | 链条**弱化**（stylo 是 blitz 的**传递**依赖，非直接） | 同 | **采纳：措辞更正** |

## 决策

### 决策 1 —— **方案 A：精确锁定**（`=` 语义），`Cargo.lock` 入库

```toml
# layout-backend/Cargo.toml（锁版）
style        = { version = "=0.20.0", package = "stylo" }   # import 名 style
stylo_dom    = "=0.20.0"                                    # 仅 ElementState/DocumentState
stylo_traits = "=0.20.0"
stylo_taffy  = "=0.3.0-beta.2"
# ⚠️ S1/P-8 实测更正：taffy 必须 default-features=false（见下方「更正注记 S1/P-8」）
taffy        = { version = "=0.14.0", default-features = false, features = [
    "std", "taffy_tree", "flexbox", "grid", "block_layout",
    "content_size", "calc", "detailed_layout_info",
] }
parley       = "=0.11.1"
selectors    = "=0.40.0"
skrifa       = "=0.44.0"
fontique     = "=0.11.1"
# ===== S6 新增直依赖（stylo 关联类型的**具名**引用；均在锁图内、同版 `=` 精确锁定）=====
# `SelectorImpl::{BorrowedLocalName,BorrowedNamespaceUrl} = web_atoms::{LocalName,Namespace}`（interned atom）
#   ⇒ `TElement::local_name()/namespace()` 需返回 `&web_atoms::*`（stylo 未再导出）——`stylo-0.20.0/lib.rs:153/156/159`。
web_atoms    = "=0.2.6"      # registry: web_atoms-0.2.6
# `TElement::query_container_size` 返回 `euclid::Size2D<Option<app_units::Au>>`；二者为 stylo 传递依赖，仅用于**命名类型**。
euclid       = "=0.22.14"    # registry: euclid-0.22.14
app_units    = "=0.7.8"      # registry: app_units-0.7.8
# 注：`TElement::id()` 返回 `&style::Atom`（= `stylo_atoms::Atom`，`style` 已 `pub use`）⇒ **无需直依赖 `stylo_atoms`**。
```

- 版本取值 = `poc/t2_4_blitz_probe/Cargo.lock` 中的整组（主理人亲验一致）。
- **S6 回填（2026-10-13）**：新增直依赖 **`web_atoms = "=0.2.6"`**（stylo `SelectorImpl` 的
  `LocalName`/`Namespace` interned atom；源码依据 `stylo-0.20.0/lib.rs:153/156/159`）与
  **`euclid = "=0.22.14"`** / **`app_units = "=0.7.8"`**（`query_container_size` 的 `euclid::Size2D<Option<app_units::Au>>`
  具名类型；均为 stylo 传递依赖）。**均与锁组同版 `=` 精确锁定**。
  **无需直依赖 `stylo_atoms`**（`TElement::id()` 返回的 `Atom` 经 `style` re-export）。
- **措辞更正（G3-B4(i) + S1/P-8）**：由「**同一锁定树**实测通过」改为
  「**经 blitz 传递**出现的整组；**直连后以 P-8 复验**」。**S1/P-8 实测证明**：`Cargo.lock` 里出现
  `taffy 0.14.0` **不等于** `stylo_taffy` 在该构建中被编译（可选依赖也进锁）⇒
  「传递编译通过」对 `stylo_taffy` 实为**未验证**，须以 P-8 锁版实测为准。

### 更正注记（S1/P-8 实测，2026-10-13）

> **实测更正**（证据 `.workbuddy/refs/g3-probe-evidence/p8-taffy-e0063-evidence.txt` 原文）：
> 决策 1 的片段里 `taffy = "=0.14.0"`（**默认特性**）**按字面不可编译**（`error[E0063]: missing fields
> clear, flex_line_count and float in initializer of taffy::Style<_>`）。**根因 = feature 统一**：
> `taffy-0.14.0` 的 `default` 含 `float_layout`/`flexbox_balance`（`taffy-0.14.0/Cargo.toml [features]`），
> 二者给 `taffy::Style` **增加字段** `float`/`clear`（`src/style/mod.rs:625/628`）与 `flex_line_count`（`:708`）；
> 而 `stylo_taffy-0.3.0-beta.2/src/convert.rs:723` 的 `to_taffy_style` 只在 **stylo_taffy 自身 `floats` feature**
> （默认**不开**，`stylo_taffy Cargo.toml [features] default = ["std","block","flexbox","grid"]`）下初始化它们
> ⇒ 字面量缺字段 ⇒ E0063。
> **处置**：`taffy` 加 **`default-features = false`** + 只开与 `stylo_taffy` 兼容的特性集（+ `taffy_tree` 供
> `TaffyTree`）。**改后编译通过**（`probe-run-output.txt` / `probe-test-output.txt`）。
> **不变量（写进 §8）**：**taffy 不得开 `float_layout` / `flexbox_balance`，除非同时开 `stylo_taffy` 的 `floats`**；
> 否则 `to_taffy_style` 字面量缺字段。
> **P-8 判定**：`P8_PINNED_GROUP_OK=true`（整组版本匹配）；`taffy` 特性面须按此**显式收窄**。
- **不可复核数字删除（G3-B4(ii)）**：删除「stylo 最新 0.22」「parley 最新 0.12.0」等**本地 registry 无**
  的版本断言（AGENTS.md 禁联网查）。
- `Cargo.lock` **入库**（既有事实 + 技术方案 §19 要求）。

### 决策 2 —— **升级流程 = 独立 PR + 全探针回归 + 裁决**

任一新依赖版本变更须：① 独立 PR（铁律 3）；② **重跑 P-1~P-11 全探针**；③ 经裁决后合并。

### 决策 3 —— 补丁通道（`[patch.crates-io]` vendor）**默认休眠**

```toml
# 默认不启用；启用须独立 PR + 书面理由 + 裁决。
[patch.crates-io]
# style = { path = "vendor/stylo" }
```

### 决策 4 —— 许可与跨平台

- 新依赖许可须在 `deny.toml` 白名单内（已核实 `stylo` 系列 MPL-2.0、`taffy` MIT、
  `parley` Apache-2.0 OR MIT 在列）；**新传递依赖若引入白名单外许可 ⇒ 上报**（**不改 `deny.toml`**，铁律 7）。
- 全部依赖须支持 **linux x86_64**（跨平台纪律）。

## 后果

### 正面
- 可重复构建；版本互斥（`stylo` 双版本）**结构性避免**；与 §19「固定 revision 验证」一致。

### 代价（如实登记）
- 放弃自动升级；每次升级须重跑探针 + 裁决。
