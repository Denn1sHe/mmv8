# G4 设计评审（从零视角 · 评审员 B）（2026-10-14）

> **方法**：先只读权威源推导「G4 必须是什么」，**再**读草案 `docs/design-g4-2026-10-14.md`。
> 推导源：docx《iv8 自研运行时完整技术方案》§18（**已读原文**）、`MEMORY.md:23`（闸门链）、G3 §6/§7 登记项、`2026-10-14-G4-设计输入清单.md`。
> **一句结论：草案不构成「诚实关闭 G4＝平台能力闭环」——它把 G4 当成了「G3 收尾批」。**

## ① 从零推导：G4 的必须项（docx §18 原文 + 全仓曾归属 G4 的登记项并集）
- **章程（docx §18 原表）**：`G4 平台能力闭环 | 必须产出 = 存储、密码、连接 fixture、图形与媒体契约、宿主 CDP 域 | 通过后开展 = 清零社区版 missing/unknown`。边界：`G5 = 全量 manifest 通过、平台包、故障/长跑、兼容报告`；`G6 = 真实 Worker、布局、真实网络、动画`。
- **M1 存储**：`StorageService` origin/top-level site 分区；`localStorage/sessionStorage`（key 顺序·字符串转换·配额·`storage` 事件·生命周期）；`CookieStore` 与 `document.cookie` **共享**同一状态；`IndexedDB`（transaction/request/cursor/版本升级/key ordering/自动提交；事件与 Promise 参与事务存活）；`CacheStorage`+`Storage Buckets` 同分区；离线默认内存存储+快照导入导出。
- **M2 密码**：`CryptoBackend` 能力表（**aws-lc-rs 优先，禁自写 AES/RSA/ECC**）；`getRandomValues`（系统 CSPRNG）；`SubtleCrypto`：AlgorithmIdentifier 归一 / `CryptoKey` 内部槽·extractable·usages / JWK·SPKI·PKCS8·raw / AES-GCM·CBC、RSA-OAEP·PSS、ECDH·ECDSA、HMAC·HKDF·PBKDF2、digest；后台预算任务 + 页面线程 resolve。
- **M3 连接 fixture**：统一 Provider 模型 `NullProvider / FixtureProvider / NativeProvider`；WebSocket·WebTransport 离线 fixture 与状态/事件；MediaElement·MediaStream 状态机+离线 fixture；Web Audio 节点/参数/离线行为；WebRTC·WebCodecs 逐方法匹配；geolocation/传感器/通知 权限与事件；网络侧 `OfflineBundle`/`HostTransport` 的 fixture 语义（**非**真实栈）。
- **M4 图形与媒体契约**：Canvas 2D；WebGL/WebGL2 参数·扩展·对象状态·错误行为；WebGPU **社区版实际暴露接口契约**；SVG 元素·`SVGAnimated*`·几何接口（渲染另列）；OffscreenCanvas 所有权；媒体/音频/编解码契约；**「可调用模拟 / 离线行为 / 真实计算」三级标记**。
- **M5 宿主 CDP 域**：宿主自提供 `DOM·CSS·DOMDebugger·Network·Page·Storage·DOMStorage·IndexedDB·Target` 等域 + **公布已支持 method/event 清单**；DOM 节点 id ↔ 真实 `NodeId` 映射；Worker = 独立 target；Elements/Application 面板由这些域支撑；「不能因 WebSocket 连上就宣称完整 CDP」。
- **M6 全仓曾归属 G4 的登记项并集（非 docx，但已被历轮 ADR/HANDOFF 分派）**：`Realm 级替换/单 Realm 旧 JS 全局残留`（`HANDOFF:60`/`TASKS:830`/`design-g2:56,506,1133`/`G2 裁决:67`）；`§16 完整兼容层`（`TASKS:832`/`gate-report-g1:41,352`/`design-g1:468,477`）；`REALM_DATA_SLOT 多 Realm 前置复查`（`design-g1:869`）；`Worker/多 Isolate 并发死锁测绘`（`remaining-scope:700`）；`timer/脚本任务化/宿主 try_borrow`（ADR-0023）；`Shadow 完整面:querySelector·retargeting·composedPath·slotchange·closed·Custom Elements`；`R22`；`R19①/R23/R24 统一走 traversal`；`动态影子重排`；`字体系统发现`；`D9 布局/几何扩展`；`动画·rAF`。
- **M7 边界提醒（属 G5，勿并进 G4）**：全量 manifest / 平台包 / 故障·长跑 / 兼容报告 / **清零 missing·unknown** / WPT runner / Chromium 差分基线。

## ④ 主理人预裁复核（从零立场）
1. **A8 网络真实栈 → G5**：**有异议（目标闸门错）**。docx §18 明列 **G6 = 真实网络**；§18-G4 要的是「**连接 fixture**」。⇒ 真实栈应 **→ G6**；**G4 必须保留 fixture 层**（`NullProvider/FixtureProvider` + WebSocket/WebTransport/媒体 fixture）。若把 S8 整体移出，则 M3 无人承接 = 章程缺口。
2. **B6 WPT runner → G5**：**同意**（§18-G5 = 全量 manifest+兼容报告）。**条件**：G4 的「通过后开展 = 清零 missing/unknown」要求 **G4 出口时就产出 manifest 缺口清单**，故 runner 的**最小可用面**（或至少缺口枚举）须在 G4 内可达。
3. **S7 = flex 基本**：**同意 flex 基本；异议其余**。transform/滚动/table·float/SVG/替换元素/表单控件 ⇒ **G6**（docx G6 明列「布局」）。若坚持留 G4，**必须落 ADR 显式重定义 G4 章程**，否则 G4 与 G6 章程重叠。
4. **R22 = ①（ADR-0021 补丁通道）**：**条件同意**。① 是对 **MPL beta 上游的长期 fork**（`stylo` 由 blitz/servo 生态维护）⇒ 必须附：**补丁文件边界 + 上游跟踪人/issue + 回收触发条件 + 独立 PR + 回归探针**（对齐 ADR-0021「补丁通道默认休眠」精神）。若 ②（手工叠加）能保持规范忠实，则**优先 ②**；② 若做不到规范忠实（输入清单已注「本身亦属具名偏差」）才落 ①。
5. **CDP 子集**：**异议**。须**先补 M5「宿主 CDP 域」**（这是 §18-G4 的原文要求），再把「Chromium 差分子集」作为 **G5 兼容报告**的手段；当前草案用「差分」顶替「宿主域」，属**实质性漏项**。

## ⑤ 结论与建议
- **草案不能诚实关闭 G4（平台能力闭环）**：M1~M5 **0/5**；M6 漏 4 项（Realm 级替换 / §16 兼容层 / REALM_DATA_SLOT / Worker 并发测绘）。**输入清单与草案均未引用 docx §18-G4 章程**（`docs/` 全库**除本评审外**无一处出现「平台能力闭环」；仅 `.workbuddy/memory/MEMORY.md:23` 记有闸门链）⇒ **缺陷在清单层，须一并修**。
- **两条出路（须主理人择一，落 ADR）**：(i) **重定义闸门**——把 storage/crypto/fixtures/graphics-media/CDP-域 显式移入后续闸门并**改名**（如把现草案更名「G3 收尾批」），使"G4"不再声称平台闭环；(ii) **补齐** M1~M5 + M6 遗漏 4 项，把 G4-S4/S7 的 G6 项让出、G4-S9 差分让给 G5。
- **不可**默认沿用旧章程而实际不交付（违反 `AGENTS.md` 铁律 10「不静默降级」与 §18「不以已有轮子掩盖成本」）。
