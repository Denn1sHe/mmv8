# R23 定点复审（评审员 A）—— stylo `ElementData` 信任契约 · 源级取证

> 只读 stylo 源码 + 本仓代码；不改码。栈与「更正」均复核一致：`data.rs:187` = `ElementStyles::primary()` 的 `.unwrap()`（`data.rs:185-188`）。

## 一、信任契约（stylo 侧，行号即证据）

1. **`borrow_data() == Some(d)` ⟹ `d.styles.primary.is_some()`**（= `d.has_styles()`，`data.rs:483-487`）。这条不是约定俗成，是被大量 `.unwrap()`/`primary()` 直接依赖的**前置条件**：`style_resolver.rs:117`（父）、`:124-125`（`display:contents` 的 `borrow_data().unwrap()`+`primary()`）、`sharing/mod.rs:259`、`sharing/checks.rs:49/50/156/194`、`traversal.rs:303`（祖先 `primary().clone()`）、`stylesheets/container_rule.rs:204/558/646`。
2. **反面形式即 stylo 自己的谓词**：`traversal.rs:255` `element.borrow_data().map_or(true, |d| !d.has_styles())` ⇒ 「**无数据 或 无 primary**」才算需重算。可见 `has_data()` 的语义 = 「**已初始化且已 styled**」，**≠「容器存在」**。
3. **`resolve_style_with_default_parents` 对祖先：只信任、不递归**。`with_default_parent_styles`（`style_resolver.rs:110-132`）：`:115 inheritance_parent()`（默认 = `parent_element()`，`dom.rs:463-465`）→ `:116 borrow_data()` → `:117 primary()`。**没有「祖先缺失则先算祖先」的分支**：拿不到数据就按「无父（root）」处理。⇒ 顺序义务归属**调用方**（须祖先先于后代解析）。
4. `resolve_style`/`resolve_style_with_default_parents` **只返回** `ResolvedElementStyles`（`style_resolver.rs:258-300`），**不写回元素数据** ⇒ **写回是调用方的义务**。

## 二、本仓违反点（真因，非 `clear_data`）

- **缺写回**：`style_system.rs:226-227` 取 `resolved.primary_style().clone()` 后**未** `element.ensure_data().set_styles(resolved)`。
- **`has_data`/`borrow_data` 恒真**：`stylo_host/dom.rs:312-318`（`has_data → true`；`borrow_data → Some(...)`），判据与 `primary` **无关**。
- **槽诞生即有名无实**：`stylo_host/mod.rs:314` `data: ElementDataWrapper::default()`（`primary == None`）；`clear_data`（`mod.rs:206-208`）仅覆盖为 `ElementData::default()`，**容器仍在**。
- ⇒ **每个元素自诞生起即 `borrow_data()==Some` 且 `primary==None`** ⇒ 任一「有元素父」的元素在 `style_resolver.rs:117` 命中 `data.rs:187` panic。这解释：**首读 OK**（首解析元素的 `parent_element()` 为 `None`：直接挂在 Document 根下）、**注册作者表后重布局 panic**（子元素的父是元素 `#c`）、**移除 `clear_data` 仍 panic**（与 `clear_data` 无关）。
- 三疑点判定：**①成立（且比「已清」更早、更结构性：诞生即违约）**；②成立（祖先数据只信任）；③**次序是次因**——只要 ①（写回+判据）修好，次序仅决定「错值 vs panic」。

## 三、对照 blitz（参考实现）

- 容器 = `UnsafeCell<Option<ElementDataWrapper>>`（`blitz-dom/src/node/stylo_data.rs:17-19`）；`has_data() = is_some()`（`:50-52`）；`get()/get_mut()` 由 `Option` 派生（`:55-62`）；`ensure_init()` 惰性建容器（`:95-104`）；**`clear() = 置 None`**（`:111-113`）⇒ 清后 `has_data()==false`、`borrow_data()==None`，**契约自动成立**。
- **写回**：解析结果 → `*stylo_data.ensure_init_mut() = stylo_element_data`（`layout/construct.rs:163-165`；`document.rs:543-544`；`mutator.rs:152`）。
- 根节点显式给 primary（`document.rs:532-544`）。⇒ blitz 三条全做，本仓三条全缺（仅「判据」一条与「写回」一条为主因）。

## 四、最小修复形态（不变式）

- **I1（必需）**：`borrow_data()/mutate_data()==Some ⟹ styles.primary.is_some()`。
- **I2**：`has_data()` 用同一判据（等价 `ElementData::has_styles()`，`data.rs:485-487`）。
- **I3**：`clear_data()` 后须 `has_data()==false && borrow_data()==None`。
- **I4（真因）**：`resolve_element_style` 必须**写回** `element.ensure_data().set_styles(resolved)`（`style_system.rs:226` 之后）。
- 两形态：**(A) 最小（零存储变更）**＝`has_data`/`borrow_data` 由 `self.data.borrow().styles.primary.is_some()` 派生 + 补 I4；**(B) blitz 同构（推荐彻底）**＝容器改 `Option<ElementDataWrapper>`（惰性 init、clear 置 None），三谓词自然一致。**推荐先 (A) 止血、(B) 作为 S 步骤收口**。
- **配对义务**：I1 单独修好会把 **panic 变成静默错继承**（父 `None` ⇒ 当 root 继承）⇒ 必须同时锁 **祖先先解析**：现有 `box_tree.rs:103-104`（`build_node` 后 `append_children`）已是 parent-first ✓，须加回归测试防退化；`display:contents` 时 `layout_parent` 也必须有 primary（否则 `style_resolver.rs:124` `unwrap()` 再 panic）。
- 根/Document 槽：仿 blitz 赋 primary（`document.rs:532-544`），消除「Document 作父」路径的同类风险。

## 五、与 R19 残余① 的相关性

**同族，且应合并登记**：R19① =「逐元素 `clear_data` 缺清理导致他元素旧值」；R23 =「逐元素 `resolve` 绕过 stylo 全量 traversal，未复刻其 `ElementData` 生命周期（**写回 + 祖先序**）」。共同根因：**自建逐元素解析取代 `driver::traverse_dom`**。建议合并为一条「ElementData 生命周期契约」登记项（S13）。
