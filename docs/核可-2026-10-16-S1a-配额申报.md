### 🟡 F8：Rust 断言 2 **恒真（自证）**，且被断言 1 完全覆盖

`crates/navigation/src/page.rs:1780-1785`：

```rust
assert_eq!(caps.storage_quota_bytes, 5 * 1024 * 1024, …);              // 断言 1：字面量 ⇒ 有判别力 ✅
assert_eq!(caps.storage_quota_bytes, storage::STORAGE_QUOTA_BYTES, …); // 断言 2
```

`caps.storage_quota_bytes` **正是由** `storage::STORAGE_QUOTA_BYTES` 赋值（`page.rs:782`）
⇒ 断言 2 实为 `X == X`，**恒真**；且任何使断言 2 红的改动（常量变 / 接线改）**断言 1 必先红**
⇒ 断言 2 **零增量判别力**（冗余）。

- 反讽点：该测注释里**正确**写道「读回 = 自证，恒绿无判别力」，但断言 2 恰好落在这个模式。
- **无害**（断言 1 承重，N2/N3 已验证判别性真实存在）。建议删除断言 2，或换成有判别力的形式（如「能力面字段集合 == `CAPABILITY_KEYS` 同集」）。

### 🟡 F9：`used_bytes(origin)` 是 **origin 合计**，却被当作「本桶已填满」的代理断言

- `crates/storage/src/lib.rs:138-141`：`used_bytes(&self, origin)` = `p.local.used_bytes + p.session.used_bytes`（**合计**）。
- `quota_is_enforced_per_bucket`（L365-369）用 `service.used_bytes(origin) == STORAGE_QUOTA_BYTES` 断言「local 桶恰被填满」—— **仅在 session 桶为空时成立**。
- 一旦 session 桶有数据，`used_bytes(origin)` 会把 session 计入 ⇒ 该断言**失真**。
- **当前绿**（session 确为空），属**断言脆弱**：未来任一笔往同 origin 的 session 写东西，本测可能**假红**（或更糟：被"顺手改期望"而静默削弱）。
- 建议：改用**逐桶**取数（如 `bucket(origin, Local).used_bytes`）作断言依据。
- **家族**：归**静默家族旁证** —— 「观测量在别的笔改动后**静默改变语义**」。
