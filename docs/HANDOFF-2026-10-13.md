## 六、坑（按血泪值排序）

1. **rsync-mtime 陈旧构建**：`rsync -a` 保留 mtime ⇒ cargo 静默跳过重编。甄别 = 日志有无 `Compiling` 行；处置 = `--checksum`。**且必须 `--exclude='.venv'`**（本地 macOS `.venv` 会覆盖远程 Linux ⇒ uv/maturin 重建；见 `docs/dev-env.md` 踩坑 #8）。
2. **远程 3.6 GB**：`-j2`；前台 ssh 长命令被 SIGTERM（用 `nohup` + 轮询）；**不许改远程系统配置**；V8 静态库走本地中转。
3. **pyo3 命名坑**：`#[pyclass]` 结构体禁用 `Probe` 作名（pyo3 内部 `trait Probe` 撞名，E0782；issue #4792）。
4. **pyo3×forbid 已解除（勿重走）**：`forbid` 下 pyo3 宏编译通过（0.29 复验）。证据 `.workbuddy/refs/pyo3-lint-probe-evidence/`。
5. **判定非恒真纪律**：四态反向验证 + 「弱门禁比没门禁更危险」。**最新范例 = D5 判别力反向注入**（倒置 ⇒ 必红 ⇒ 还原哈希一致）：`.workbuddy/refs/g2-qa-evidence/r2-d5-inverted-red.txt`。
6. **「空返回纪律」（ADR-0015）**：V8 宿主回调空返回**仅限存在挂起异常**——G2 起所有宿主回调（fetch/网络/模块/未来）适用；违者进程级 FATAL。
7. **协作消息穿越坑**：对运行中的 teammate 发指令可能被错过 ⇒ 关键指令在对方空闲时补「开工确认令」双保险（本轮多次实例）；改动「报告与指令交错」时以磁盘证据复核。
8. **数字口径**：workspace 158 / contracts 60 / sdk-python 22；覆盖率 83.47%R / 82.66%L。**引用前先跑一遍**。
