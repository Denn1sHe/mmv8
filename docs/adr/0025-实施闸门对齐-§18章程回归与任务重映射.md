## §1 背景与漂移根因

一轮「G4 设计草案」**误以「运行时可交互动面 + G3 机制收口」为 G4 主题**。

**漂移根因（架构师自陈）**：`2026-10-14-G4-设计输入清单.md` 的编制**只引用了 §0.2/§6/§7 的 G3 台账**，**未回引 docx §18 章程**；而 §18 对 **G4 = 「平台能力闭环」**（存储/密码/连接 fixture/图形与媒体契约/宿主 CDP 域）有**明文**定义 ⇒ 术语「G4」被**误用**，草案实为 **G3 机制债务的收尾**。

**同源病根（既有教训族）**：「**未回引权威基准**」—— 与「静默丢测 / 幽灵 `.so` / CI 三红案」同族：**输入面缺失 ⇒ 结论偏差而不自知**。**纠正手段 = 章程回引 + 词汇重定 + 任务重映射**（本 ADR）。

## §2 §18 闸门表（**原文逐字**，回归章程）

| 闸门 | 必须产出 | 通过后开展 |
|---|---|---|
| **G0 契约冻结** | 社区版接口清单、证据来源、行为级别、测试 runner 与模式定义 | 所有模块按 manifest 拆分责任。 |
| **G1 引擎纵向验证** | 原生绑定、模块/WASM、微任务、GC 循环、控制入口隔离、Python 回调 | 正式生成 Web IDL 绑定和 DOM。 |
| **G2 页面纵向验证** | 流式解析、阻塞脚本、document.write、导航、资源等待和输入 | DOM/CSSOM/API 广度扩展。 |
| **G3 布局复用验证** | Blitz/Stylo 适配、动态失效、字体、几何和 **Shadow 用例** | **确定布局后端，开展完整尺寸与动画。** |
| **G4 平台能力闭环** | **存储、密码、连接 fixture、图形与媒体契约、宿主 CDP 域** | **清零社区版 missing/unknown。** |
| **G5 社区版等价发布** | 全量 manifest 通过、平台包、故障/长跑测试、兼容报告 | 可作为业务内核替代社区版。 |
| **G6 Pro 扩展发布** | 真实 Worker、布局、真实网络、动画各自的能力与差分报告 | 按后端与测试范围逐项交付。 |

> 章程另注（§18）：**G3 通过后**「确定布局后端，**开展完整尺寸与动画**」⇒ **完整布局/尺寸/动画属 G3 之后**（非 G3 内）。

## §3 决策

### 3.1 术语重定（词汇重定）
- **「G4」** 唯一指 **§18 G4 = 平台能力闭环**（存储/密码/连接 fixture/图形与媒体契约/宿主 CDP 域）。
- 前一轮「G4 草案」的实质 ⇒ 正名为 **「G3 收尾批」**（**G3 机制债务的诚实兑现**）。

### 3.2 任务重映射（旧草案各项 ⇒ 新归属）

| 旧草案项 | 内容 | **重映射** |
|---|---|---|
| `G4-S1` | 统一走 stylo traversal（R19①/R23/R24 机制收口） | **G3 收尾批** |
| `G4-S2` | 字体系统发现接线（`fontique system_fonts` + CJK fallback） | **G3 收尾批**（§18 G3「字体」面） |
| `G4-S3` | 执行模型收口（timer / 脚本任务化 / 宿主 `try_borrow` 残余） | **G3 收尾批** |
| `G4-S4` | 动画 / rAF | **G6**（§18 G6「动画」+ G3 后「开展…动画」） |
| `G4-S5` | Shadow 完整面（`:host`/`::slotted` + `querySelector` + retargeting + `composedPath` + `slotchange` + Custom Elements） | **G3 收尾批**（§18 G3「Shadow 用例」） |
| `G4-S6` | 动态影子重排 | **G3 收尾批** |
| `G4-S7` | 范围扩展（flex 基本 / 滚动 / transform / table/float / SVG / 替换元素 / 表单） | **G6**（§18「布局」面） |
| `G4-S8` | 网络真实栈（A8） | **G6**（§18 G6「真实网络」） |
| `G4-S8` | WPT runner（B6） | **G5**（等价性仪器，配合「全量 manifest」） |
| `G4-S9` | CDP：**宿主 CDP 域** | **G4**（§18 G4 明列；**M5**） |
| `G4-S9` | CDP：Chromium **差分** | **G5** 手段（「兼容报告」） |
| `G4-S9` | sdk-python 口径 / 覆盖不回落阈值 | **G3 收尾批 / QA 季** |

### 3.3 修正主理人此前两处预裁（自我纠正，如实登记）
1. **A8 真实网络 ⇒ 归 G6**（**非 G5**）—— §18 G6 明列「真实网络」；**G4 保留「连接 fixture 层」**（Null/Fixture/Native Provider + WS/WT/媒体 fixture）= **G4 的 M3**。
2. **S7 全部 ⇒ G6**（含「flex 基本」，不再保留 G4 内）；**S4 动画/rAF ⇒ G6**。

### 3.4 G4 真身（= §18 平台能力闭环，M1~M5）

| 模块 | §18 G4 对应 | 要点 |
|---|---|---|
| **M1 存储** | 存储 | localStorage / sessionStorage / IndexedDB（面与级别以 manifest 为准） |
| **M2 密码** | 密码 | Credential Management / 密码域（面以 manifest 为准） |
| **M3 连接 fixture** | 连接 fixture | **Null / Fixture / Native Provider** 三层 + **WS / WT / 媒体 fixture**（离线可控） |
| **M4 图形与媒体契约** | 图形与媒体契约 | Canvas/媒体**契约层**（非重型实现） |
| **M5 宿主 CDP 域** | 宿主 CDP 域 | **本仓宿主侧 CDP 域实现**（非 Chromium 差分） |
| **目标** | — | **清零社区版 `missing` / `unknown`**（`contracts/compat-manifest.json`） |

### 3.5 词汇/编号约定（防再漂移）
- 设计文档**首段必须回引 §18 对应闸门**；
- 旧「G4-S‹n›」编号**作废**，收尾批改用 **`G3X-S‹n›`**；真 G4 用 **`G4-S‹n›`**（重新起始）；
- 输入清单 A/B/C 编号**不外溢**（承前约定）。

## §5 机器可验证门禁

| 决策 | 门禁 | 形式 |
|---|---|---|
| 闸门对齐 | 设计文档首段含 **§18 闸门回引**；术语表无「G4=机制收尾」误用 | 文本检查 |
| G4 目标 | `contracts/compat-manifest.json` 的 `missing`/`unknown` **计数单调下降至 0** | 脚本（沿用「**统计分母固定、不允许删测试**」） |
| 词汇 | `G3X-S*`（收尾批）与 `G4-S*`（真身）**前缀不混用** | 文本检查 |

## §6 后果

- **术语止血**：此后「G4」不再指代机制收尾；**收尾批**与 **G4 平台能力闭环**各归其位。
- **正面收益**：评审 B 的证伪**使偏差在冻结前被捕获** —— 印证 G2/G3 双评审机制的价值。
- **遗留**：收尾批定稿待 **评审 A 书 + QA 报告**；G4 真身设计骨架待起草（M1~M5）。
