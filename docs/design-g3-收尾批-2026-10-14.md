## §1 目标 / 范围 / 非目标

### 1.1 目标
把 G3 的**静态布局/样式/影子**面推进为**可交互动运行时**，并收口 G3 遗留的**机制性欠账**（自建逐元素解析绕过 stylo traversal）。

### 1.2 范围（六组）
- **G4-A 机制收口**：统一走 stylo traversal（`G4-S1`）；字体系统发现接线（`G4-S2`）。
- **G4-B 执行模型**：timer / 脚本任务化 / 宿主 `try_borrow` 残余（`G4-S3`）；动画 / rAF（`G4-S4`）。
- **G4-C Shadow 完整面**：`:host`/`::slotted` 样式级联 + `querySelector` + retargeting + `composedPath` + `slotchange` + Custom Elements（`G4-S5`）；动态影子重排（`G4-S6`）。
- **G4-D 范围扩展（CSS/几何）**：flex/grid 完整、transform、滚动、table/float、SVG、替换元素、表单控件、几何读数扩展（`G4-S7`）。
- **G4-E 资源与测试面**：网络真实栈、WPT runner（`G4-S8`）。
- **G4-F 质量口径**：CDP/真实 Chromium 差分、sdk-python 口径、覆盖不回落阈值（`G4-S9`）。

### 1.3 非目标（⇒ G5 / G6，显名）
- **G5（内存/性能批）**：句柄零泄漏（arena 池 / `self_cell` / `ouroboros`；**换型须重走 R18 硬边界**）；大规模性能基线。
- **G6（完整 Web 平台面）**：WPT **全量**、Custom Elements 全生命周期、完整 CSS 全属性。
- **持续非目标**：CDP 全量一致性（G4 仅做**子集差分**）。

### 1.4 判据延续（G3 规则不放松）
- **自洽 + 具名偏差**（G3-B3）；`capabilities` **不写 `full`**；
- **收集数下限哨兵**（`COLLECTION_FLOOR=60`，仅升）；
- **教训族**入 CI/脚本：静默丢测 / 锚点补丁回读 / 幽灵 `.so`（recipe）/ 后台命令消除交互提示 / CI 三红案（同病根依赖）。

## §5 G5 / G6 交接面

- **→ G5（内存/性能批）**：句柄零泄漏候选（arena / `self_cell` / `ouroboros`）；性能基线（restyle 增量、`build_slots` 频度）。
- **→ G6（完整 Web 平台面）**：WPT 全量、Custom Elements 全生命周期、完整 CSS 全属性、CDP 全量一致性。
- **G4 出口条件**：`G4-S1/S3/S5`（P0）全绿 + `§4` 矩阵通过 + 哨兵/教训族在 CI 生效。

## §6 依赖 / 包

- **Rust**：沿用 G3 钉版（`style`/`stylo_dom`/`stylo_traits`/`stylo_taffy`/`taffy`/`parley`/`selectors`/`skrifa`/`fontique`）。
- **G4 新增（候选）**：无（**优先复用**；如需 vendor 补丁 ⇒ 走 **ADR-0021**）。
- **Python/CI**：`pytest` + 收集数哨兵；`ci.yml` 系统依赖（`pkg-config` + `libfontconfig1-dev`）。
