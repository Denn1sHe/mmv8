- **状态**：**全文草案**（架构师起草，2026-10-15；**骨架 `design-g4-真身-2026-10-14.md` 为本稿前身**）。**流程**：主理人**逐项裁 §7** → **两条独立评审** → **冻结**。
- **章程依据（回引，ADR-0025 约定）**：`docs/iv8自研运行时完整技术方案.docx` **§18 G4 平台能力闭环**：
  - **必须产出** = **存储、密码、连接 fixture、图形与媒体契约、宿主 CDP 域**；
  - **通过后开展** = **清零社区版 `missing`/`unknown`**。
- **出口（G4 门禁）**：`contracts/compat-manifest.json` 的 **`missing` / `unknown` → 0**（**分母固定，不许删测试/条目提数**，沿用 §18 社区版等价发布条文）。
- **现状**：`contracts/compat-manifest.json` = `{"version":1,"entries":[]}` ⇒ **G4 首步即立 manifest 基线（M0）**。
- **编号**：真身用 **`G4-S‹n›`**（与 `G3X-S‹n›` 不混用）。
- **制度沿革（全部沿用）**：**设计首段回引 §18**；**判别力 + 负对照**（每断言含**钉值 + 负对照**，**弱门禁不得「通过」**）；**教训族**（六块 + **静默家族**）；**两条独立评审后冻结**。

## §1 范围 / 目标 / 非目标

### 1.1 范围（= §18 G4 五项，`M1`~`M5` + 基线 `M0`）

| # | 模块 | 范围一句话 |
|---|---|---|
| **M0** | **manifest 基线** | 填充 `compat-manifest`（**interface 清单 / 证据来源 / 行为级别 / runner / 模式**）+ **分母固定声明** |
| **M1** | **存储** | `localStorage` / `sessionStorage`（**先行**）+ **IndexedDB 面级契约**（详见 §7-1） |
| **M2** | **密码** | Credential Management **行为级**（详见 §7-2） |
| **M3** | **连接 fixture** | **三层 Provider**（`Null` / `Fixture` / `Native`）+ **WS / WT / 媒体 fixture**（离线可控、可复现） |
| **M4** | **图形与媒体契约** | Canvas / 媒体 / **字体** 的**契约层**（trait 边界 + 占位/透传；**非**重型实现） |
| **M5** | **宿主 CDP 域** | **本仓宿主侧** CDP 域（**非** Chromium 差分） |

### 1.2 非目标（**显名**，⇒ 他闸）

- **真实网络（在线传输）** ⇒ **G6**；G4 只做 **连接 fixture 层（M3）**（`Native` 面见 §7-3）。
- **重型图形 / 媒体实现**（编解码、渲染后端） ⇒ **G6**；G4 只做**契约层（M4）**。
- **Chromium 差分** ⇒ **G5** 手段（G4 只做**宿主 CDP 域 M5**）。
- **完整布局 / 动画** ⇒ **G6**（§18：G3 之后「开展完整尺寸与动画」）—— **`box_tree` 扁平化面随此归位（§7-7）**。

## §5 质量面（复用输入清单 **C / E**）

- **C1 CDP 差分** ⇒ **G5**（G4 只做宿主 CDP 域）；**C2 sdk-python 口径**（惯例口径、非真盲区）；**C3 覆盖软点**（以 §4 矩阵覆盖）；**C4 不回落阈值**（**留 QA 季**；若设 ⇒ **小容差 + 具名理由**）。
- **E 不变量**：**收集数下限哨兵**（`COLLECTION_FLOOR`，**仅升**）；**门禁双端**（pivot 后按本地）；**教训族**（**六块 + 静默家族**，见 §8）。
- **本批新增不变量（承 G3X）**：**逐测试「钉值 + 负对照」**；**每新面验收专项自问「失败时观测量会不会变？」**（**若不会 ⇒ 空门禁**）。

## §6 与 compat-manifest 挂钩

- **schema**：`{ "version": 1, "denominator_fixed": true, "entries": [ { "id", "source", "behaviour", "runner", "mode", "evidence" } ] }`（五要素 = **G0 契约冻结**口径）。
- **出口门禁**：`missing` / `unknown` **单调下降至 0**（`G4-S6`）。
- **分母固定（§18 条文）**：**不许删测试 / 条目提数**；**分母哨兵**（`4.0`）机器强制。
- **证据来源**：每条目须可追（**回引 ADR-0025 闸门对齐**）。

## §8 制度 / 冻结（**全部沿用**）

1. **章程回引**：**设计首段回引 §18**（本稿头部已回引；**正文各处再引具体条**）。
2. **判别力 + 负对照**：**每断言含「钉值 + 负对照」**（§4 全表）；**弱门禁不得「通过」**。
3. **教训族**（**六块**）：全仓扫查 / 清单以符号为准 / 批量替换不可信 / 注释·字符串非站点 / 夹具亦须真实性 / 夹具形状须多样；**+ 「静默家族」（跨批次复发：`R19`/片1/`S5b`/`INJ-④②`）**；**验收专项自问「失败时观测量会不会变？」**。
4. **弱门禁防线**：**`missing`/`unknown` 只认 0**；**分母哨兵**（`4.0`）；**逐条目证据可追**。
5. **冻结流程**：**主理人裁 §7 → 两条独立评审（reviewer-a / reviewer-b）→ 冻结**（**冻结后仅显式升版**）。
