## §1 本体：改了什么（自读源码核对）

1. `crates/engine-v8/src/error.rs`：`JsError` 增 **`name: Option<&'static str>`** 具名槽 + `JsError::named(kind, name, message)` + `name()` 取值；`new()` 恒 `None`（**无静默默认名**）。
2. `crates/engine-v8/src/native_fn.rs`：`throw_message` 由「`v8::Object::new` 裸对象 + 只设 `message`」改为 **`v8::Exception::error`（真 `Error` 实例）**，并新增 `throw_named` 在具名时写 `name` **自有属性**；四条 `throw_message(..)` 调用点全改 `throw_named(..)`。
3. `crates/navigation/src/binding.rs`：**撤销 `S1-a` 的哨兵绕行** —— `setItem` 超配额由「返回 `"QuotaExceededError:{quota}:{attempted}"` 哨兵串 + shim 解析重抛」改为**宿主 `Err(JsError::named(..))` 直抛**；`SHIM` 中对应 `indexOf('QuotaExceededError:')` 分支整段删除。
   - 自核：`SHIM` 中已**无** `catch` / `indexOf` / `throw` / `Error` 残留 ⇒ **绕行清干净** ✅。

## §2 负对照 —— ✅ 实跑变异，2 组全红

| # | 变异（我做的） | 预期 | 实测 |

| **MA** | `throw_named` **退回旧实现**（`v8::Object::new` 裸对象 + 只设 `message`） | 第 1 条断言红 | ✅ **红**：`宿主具名错误应是 Error 实例` — `left: Bool(false)` / `right: Bool(true)` |

- 反向可推：`String(e)`（第 3 条）与 Rust 侧 `message` 含具名（第 4、5 条）依赖前两者，构成**递进链**。

### 🟡 F11：本次改动面**大于 `D4-M` 本身** —— 属**全局行为变更**，但未被具名
