## 六、坑（按血泪值排序）

1. **rsync-mtime 陈旧构建**：`rsync -a` 保留 mtime ⇒ cargo 静默跳过重编、直接跑陈旧二进制。甄别 = 日志有无 `Compiling` 行；处置 = `--checksum` 或 touch（touch 只改 mtime、不改内容，两端 sha256 可核）。详见 `docs/dev-env.md` 注意事项 7。
2. **远程 3.6 GB**：链接 V8 用 `-j2`；前台 ssh 长命令会被 SIGTERM（用 `nohup` + 轮询）；**不许改远程系统配置**；V8 静态库走本地中转 `RUSTY_V8_ARCHIVE`。
3. **pyo3 命名坑**：`#[pyclass]` 结构体**禁用 `Probe` 作名**（pyo3 内部有 `trait Probe`，撞名报误导性 E0782；issue #4792）。
4. **pyo3×forbid 已解除（勿重走）**：`forbid` 下 pyo3 宏编译通过（0.29 复验）；反向注入证明 lint 武装。证据 `.workbuddy/refs/pyo3-lint-probe-evidence/`。
5. **判定非恒真纪律**：凡「改了 X 之后 Y 变了」类断言，必须有「只改 X」的对照组 + 反向验证四态（注入红 / 放松绿 / 恢复红 / 清理绿）；**恒假门禁比没有门禁更危险**。
6. **数字口径**：engine-v8 43 + vertical 1 = 引擎侧 44；全 workspace 54；contracts 55；sdk-python pytest 13；覆盖率 75.33%R / 75.97%L。**引用前先跑一遍**。
