## 二 D1~D4 裁决

### D1（直连 Stylo+Taffy+Parley）——**维持方向，更正表述 + 机制入探针**
- **维持 `SWITCH_TO_STYLO`**。
- **核心理由表述更正**：「自建绕开 OpaqueElement 限制」→「**我方与 blitz 面对同一个 opaque/rehydrate 问题**；差异在于**策略自主**：`OpaqueElement` 是 `Copy+Eq+Hash` 的 64-bit 句柄（可作侧表键），而 `implicit_scope...` 是无 self 关联函数 ⇒ **必须线程局部/全局侧表**反查（锚点稳定策略 + 生命周期管理），**路径可行性以待 P-1 实测**；blitz 因以 NodeId 作 opaque、需 Slab 反查而受制，修形须改上游（不在我方掌控）」。
- **P-4 失败 ⇒ 停止**，重新评估备选（blitz+上游修形等），不静默换路。
- brief 备选 B 的「结构性限制」措辞更正为「上游设计所限、修正不可控于本仓」；备选「blitz+上游修形」入册。

### D2（锁版与补丁策略）——**采纳方案 A + C 通道（默认休眠）**
- 精确锁定 t2_4 实测组（`=` 语义）+ `Cargo.lock` 入库（既有事实）+ 升级流程 = 独立 PR + 全探针回归 + 裁决；
- 补丁通道（`[patch.crates-io]` vendor）**默认不启用**，启用须独立 PR + 理由 + 裁决。

### D3（工具链钉版）——**钉 `1.92.0`**，附带两项
- `rust-toolchain.toml` → `channel = "1.92.0"`（本地/CI 现成；远程 `rustup toolchain install` 属用户级授权）。
- **① MSRV 事实更正**：`rust-version = "1.85"` 已被 **parley 0.11.1（1.88）** 实质违背 ⇒ ADR-0022 须如实登记并给出处置（更新为实测下限 / 标注「声明即验证、待 cargo-msrv 回写」）——**不得以 1.85 假声明继续**。
- **② CI 矩阵收敛**（`["stable","1.92.0"]` → 与钉版一致）：**列为「待维护者批准」条**（铁律 7），不阻塞钉版先行；`ci.yml` 在批准前**零改动**。

### D4（遗留项排程）——**修正为三分**
- **timer 事件循环 → G4**（施工图 §3.3 四条失效测试**全部同步可完成**，两评一致已证）；
- **脚本任务化 + 宿主 `try_borrow` → G4**；
- **模块 watchdog（U-12）→ 抽出为独立 P0 小步，在 G3 内完成**（安全缺口、与布局无耦合；含测试「模块死循环 ⇒ `Terminated`」）；施工图 S12 中 watchdog 与 timer 的绑定结构**拆开**。

## 四 探针强化（S1 门，修订版 P-1~P-11）

- **P-1（强化·前置门）**：投影编译 + 一次级联 + **opaque/rehydrate 侧表机制**（建 ≥2 节点，走 `opaque()`→关联函数反查路径）；判定 = 编译 + 反查命中 + **零 unsafe**。
- **P-2（强化）**：经 stylo→taffy 桥的「样式→布局」联动（G3-B9）。
- **P-3 / P-6 / P-7 / P-8 / P-9**：维持（两评支持）。
- **P-4（重定义）**：真实 web-dom 模型上：`attach_shadow` + 影子根内作者表 `:host`/`::slotted` **经 implicit scope 生效**（判定含 G3-B1 机制步骤）+ light 查询不含影子内容。
- **P-5（降级）**：自洽口径 + 偏差登记（G3-B3）。
- **P-10**：容差 ≤0.5px。
- **P-11（新增）**：prefs/初始化路径在无 GUI 环境的可运行性。
