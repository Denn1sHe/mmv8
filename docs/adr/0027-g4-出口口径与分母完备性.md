# ADR-0027：G4 出口口径、分母完备性与「遗漏九族」收口

- **状态**：**已定（2026-10-15）**；来源 = **主理人合并裁定包 `R-1`~`R-10`** + **评审书 A（证伪）/ B（从零）**；落地稿 = `docs/design-g4-真身-2026-10-15.md`（**v3 并稿**）。
- **章程依据**：`docs/iv8自研运行时完整技术方案.docx` §18（*"G4 平台能力闭环 … 通过后开展 清零社区版 `missing`/`unknown`"*）。

## §1 出口口径加严（**决定：加严，且显名**）

- **§18 原话**：「清零社区版 `missing`/`unknown`」是 **G4 通过后的「开展」**；
- **本仓决定**：**把「清零」前置为 G4 出口门禁（`G4-S6`）—— 加严**；
- **理由**：**可执行门禁优于文书口号**（沿用 G3X 由「G0 契约冻结」得出的同一判据）；**避免与 `G5`「全量 manifest 通过」同义反复** ⇒ **G4 出口 = `missing`/`unknown == 0`；`failed` 非零须逐条具名理由 + 白名单**。

## §2 出口与 `BLOCKING_STATUSES` 对账（**决定：对齐既有实现**）

- `contracts/iv8_contract/manifest.py:67-69`：`BLOCKING_STATUSES = {FAILED, MISSING, UNKNOWN}`、`is_release_blocking()`；
- **决定**：**G4 出口沿用该函式语义** —— **`missing`/`unknown` 归零为硬门禁；`failed` 允许非零但须「逐条具名理由 + 白名单」**（**消除「同仓两套阻断定义」**）。

## §3 分母完备性（**决定：外部锚定 + 双向核 + 冻结时点**）

- **分母定义源 = §18 接口清单**（**已机读落库**：`docs/refs/iv8-docx-G4-平台能力-提取-2026-10-15.md`）；
- **社区 `v0.1.4` 双模式实测（`cases` 的 `spec_expect`/`iv8_expect`）= 证据来源，非定义源**；
- **完备性验收（新增行 `4.7`）**：**`社区清单成员集 ⊆ manifest 成员集`**（**逐成员；未达显名 `missing`**）∧ **无清单外杜撰 `id`**（**双向核**）；
- **分母冻结时点 = `S0` 结束**（修正 `denominator_fixed` 语义）；
- **`G0` 欠账（无「冻结 `.md` 文书」）在 `M0` 显名登记** —— **「G0 契约冻结」的实质 = 机制（`manifest.py` + `cases`），非文书**。

## §4 「遗漏九族」收口（**决定：九族全部「进分母」，显名登记**）

`CacheStorage`/`Storage Buckets`｜`WebGL`/`WebGPU`/`SVG`/`OffscreenCanvas`｜`Web Audio`/`MediaStream`/`WebRTC`/`WebCodecs`｜编码文件与 URL｜`Streams`｜安全与权限｜设备与通信｜Worker 家族社区版契约｜`storage` 事件（跨文档）。

- **决定**：**九族全部「进分母」**（**社区契约层**，**保守最大集**，主理人 2026-10-15 照准）；**真实实现 ⇒ G6**；
- **纪律（主理人 2026-10-15 附）**：**`S0` 种子填充时，若发现某族与社区版 `v0.1.4` 实际面貌不符 ⇒ 以本 `ADR` 显式移出（具名理由）；不许静默删** —— **不得默默缺席**；
- **落点**：见设计 `§10` 收口表。

## §5 关联

- **`R-1`**（schema 9 字段 / `behavior_level` 三态 / 证据派生）｜**`R-4`**（密码 = WebCrypto + Credentials 两家族）｜**`R-5`**（CDP 外部锚定最小集 + 「已支持清单」交付物）｜**`R-6`**（IDB 未达成员逐员 `missing`）｜**`R-8`**（`INJ` 制度化）；
- **静默家族（跨批次复发）**：本 ADR 的 **`§3` 双向核** 与 **`§1` 加严显名** 均为**针对「分母起点选小」**这一静默家族第 1 型**的机器防线**。

## §6 粒度续条（**成员定义 = WebIDL `.member`**；`R-3` 续；2026-10-15/16）—— **架构师草（待主理人审 → 入卷）**

> **取材**：`docs/decision-briefs/2026-10-16-G4-S0b-成员枚举计划.md`（工程师，142 行；`§1` 成员 id 规范 + `§3` 兜底范围）。

### 6.1 「成员」定义

- **成员 = WebIDL 语义 `<Interface>.<member>`**（**含点**，**成员级**）：**属性 / 方法 / 常量 / 事件**（**四类**；**事件按 `on<name>` 记为接口成员**）。
- **与既有门禁对齐**：`manifest.py` 的 `"." in id` **强制** ⇒ **族级名（如 `"Window"` 无点）当场拒**；**跨族接口**（如 `SVGAnimatedLength.baseVal`）**同规则**。

### 6.2 进分母的接口族域（**兜底范围 = `§11`/`§12` 已具名族，不外扩**）

| 族（提取件已具名） | 候选接口（示例，**非穷举**） |
|---|---|
| **存储** | `Storage` / `StorageManager` / `StorageBucketManager` / `IDBFactory` / `IDBDatabase` / `IDBTransaction` / `IDBObjectStore` / `IDBIndex` / `IDBCursor` / `IDBRequest` / `CacheStorage` / `Cache` / `CookieStore` |
| **密码** | `Crypto` / `SubtleCrypto` / `CryptoKey` / `Algorithm` 系 |
| **图形媒体** | `CanvasRenderingContext2D` / `OffscreenCanvas` / `WebGLRenderingContext` / `WebGL2RenderingContext` / `WebGPU` 系 / `AudioContext` / `AudioNode` / `HTMLMediaElement` / `MediaStream` / `WebSocket` / `RTCPeerConnection` 系 |
| **编码文件** | `TextEncoder` / `TextDecoder` / `Blob` / `File` / `FileReader` / `URL` |
| **设备** | `Geolocation` / `Notification` / `Clipboard` |
| **宿主 CDP（`§13`）** | 域 × method/event（`Runtime.*` / `Debugger.*` / `DOM.*` / `CSS.*` / `Network.*` / `Page.*` / `Storage.*` / `DOMStorage.*` / `IndexedDB.*` / `Target.*`） |

> **防分母无界**：**只对提取件「已具名」的族枚举**，**不外扩**。

### 6.3 枚举方法学（**两候选源 + 可复现命令**）

- **候选 A（定义源·首选）= 社区 `v0.1.4` 实物自省**：
  - **A-1「Python 面」**：`inspect.getmembers(iv8.JSContext)`（模块 + 主入口 + 导出名）；
  - **A-2「JS 面」**：**经 `iv8` 的 `eval` 通道自省** `globalThis`（构造器）+ 各原型成员（**不依赖浏览器**）；
  - **产出**：`contracts/community-v0.1.4-members.json`；**前提 = 维护者提供实物位置**（**本仓 `poc/` = 我方 spike，非社区实物**）。
- **候选 B（兜底）= 规范面 WebIDL**：**以 WebIDL 文本为输入，逐接口抽成员**（属性/方法/常量；**纯文本、无外部依赖**）；**触发条件 = 维护者无可枚举实物**。
- **产出格式（`load_members` 认可）**：`{ members[], source, method, extracted_at, needs_community_review }` —— **`members` 非空**（**fail-closed**）；**`source`/`method` 随文件入库（可追性）**；额外键被容忍。
- **可复现性**：**`method` = 逐字可复现命令**；**`test_ids` 由 `cases/` 双模式探针补齐**（`R-3`：**探针 = 证据来源，非定义源**）。

### 6.4 定义源层级条款（**硬**）

| 源 | 层级 | `needs_community_review` | 备注 |
|---|---|---|---|
| **社区 `v0.1.4` 实物自省** | **定义源** | `false` | **首选** |
| **规范面 WebIDL** | **兜底（显名待核）** | **`true`** | **非定义源 ⇒ 须显名**（`§14`：待社区实物复核） |

- **纪律**：**禁用同名构造器补足计数**（docx 自证）；**粒度不可达 ⇒ 停报（不编造）**；**两源口径差 ⇒ 具名登记**；**任何移出 ⇒ 本 `ADR` 显式记录**（`§4`）。

## §7 `S0` 进度注（2026-10-15）

- **`S0a` ✅**（`6b957b3`）：**九字段 schema** + **`behavior_level` 三态 + 证据派生** + **完备性 `fail-closed` 双门禁**（空表/漏/造 三红）+ 18 测；**`floor 60 → 78`（只升，理由注）**；`denominator_fixed: false`（合「冻结时点 = `S0` 末」）。
- **`S0b` = 停报（**受阻，显名**）**：工程师源级取证 —— **`§18` = 闸门表 / `§14`·`§15` = 面级三栏 / `§9`·`§11`-`§13` = 散文 + 面级表** ⇒ **成员级源天然不存在**（**文档自证**：*"仍须展开到成员…"*、*"manifest 不得用同名构造器补足计数"*）⇒ **成员级定义源待定（见 `§6`）**；**`M0b` 因此受阻** —— **显名，非静默** ✓（**双门禁 `fail-closed` 保证无静默假通过**）。
