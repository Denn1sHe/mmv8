## §4 教训族指针（**六块 + 静默家族 —— 不重复正文**）

- **六块 + 静默家族** ⇒ `docs/g3x-收官尾账-2026-10-15.md` **`§4` / `§4.1`**（**本体在此，本台账只指**）。
- **G4 期新增纪律（增量）**：**达成层级**（`behavior_level` 三态 + 证据派生 + 错标 ⇒ 红）｜**归属判初判**（实证后经 ADR 修订）｜**生成物口径**（命令+哈希）｜**分母完备性双向核**｜**枚举器须自防静默丢成员**（`options = {}` 花括号配平案 ⇒ **静默家族旁证 +1**）。
- **本班（2026-10-16 夜）新增四条**（源级核可产出，**静默家族**为主）：
  1. **「生成器覆写纪律位」** —— 任何**重跑即覆写**的产物生成器，凡触碰**纪律标志位**（`denominator_fixed`）**必须显式保留或显式拒绝**，不得"顺手写默认值"。实证：`F1`（冻结位 `true⇒false`，CI 绿、台账 ✅、实物已翻）。
  2. **「冲突判据须用不可归并的键」** —— 唯一性/冲突门禁的判定键若用**会被归并的标签**（两源共用 slug）⇒ 对归并后同名项**恒不触发**。判据应取 `source_version` 等**逐源唯一**键。实证：`F2`/`U-9`。
  3. **「枚举器正则须覆盖类型语法全集」** —— 本族**第三例**（`mixin` / `options={}` / **联合类型**）。新教训：**判别"纯静默"要看排除分支** —— 本例因 `_METHOD` 把 `attribute` 列入排除名，才**既不报错也不产错条目**。实证：`F3`/`U-8`。
  4. **「`floor` 哨兵守不住重名覆盖」** —— 测试**重名重复定义**时后定义补位 ⇒ **收集数不降** ⇒ `floor` 不红，但前一份是**死码**（改了等于没改）。与「漏 `test_` 前缀」同族但**现有哨兵覆盖不到** ⇒ 须另加**重名检测**。实证：`F4`。
  5. **「负对照须实跑变异验证」**（**核可制度纪律**，主理人 2026-10-16 令正式入族）—— 注释里写了"改 X ⇒ 红"**不算数**；核可方须**自己改码跑一遍看是否真红**。本班 **8 组变异全部真红**（⑥ 的 N1/N2/N3、`D4-M` 的 MA/MB、`F1` 的 N1/N2/N3 之外，含 `F12` 的 NA/NB）。**副产物价值**：变异能反查出「哪条测是某语义的**唯一承重者**」（如 `quota_is_enforced_per_bucket` 是 per-bucket **唯一**承重 —— 变异后 storage 6 测中仅它红）与「两维度是否**互不覆盖**」（`D4-M` 的真 Error 实例 × 具名槽）。**这是对静默家族最有效的机器反制。**
  6. **「声明态 ≠ 实物态」**（**`F1` 与 `F7` 的共同根**）—— 台账写 ✅ / HANDOFF 写 `true` / ADR 写"已冻结"，**都不是实物**。实证①：`F1`（`denominator_fixed` 实物 `false` 而三处文档皆记 `true`）；实证②：`F7`（`status` 全 `missing`、`test_ids` 全 `g4-seed:pending`，而台账已记「`S1-a` ✅ 全闭合」）。⇒ **纪律**：凡"已完成/已冻结/已流转"类声明，**必须有读实物的断言**，否则一律视为**未证明**。
  7. **「假流转」**（`F7` 的变体，**静默家族**）—— `status` 升 `verified` 而 `test_ids` 指向**不存在**的测试名 ⇒ 观测量（verified 计数）**上升**，实际**零证据**。⇒ **须加机器断言**：「`verified` 条目的 `test_ids` 必须指向**真实存在**的测试」。与主理人裁定一致。
  8. **「陈旧编译产物 ⇒ 观测量测的是旧码」**（本人踩到，与「幽灵 `.so`」同族）—— 核可时首次单跑某测得 **FAILED**，跑全量却全绿：原因是复用了前一提交的**陈旧编译产物**、未触发重建。⇒ **纪律**：**核可单测结论前必须先确认产物已重建**（先跑一次全量，再筛单测）。
  9. **「源级对撞：假红优于假绿，但不得放宽正则」**（`U-14`/`F16`）—— 读源码文本的对撞测，遇到**行为正确但形态变了**（如把具名抽成常量）会**假红**。裁定：**接受**（假红是显式决策点，假绿才是静默）。⇒ **纪律**：抽常量时**同步改正则**，**不得**以"行为明明是对的"为由放宽正则（放宽 = 削弱守卫）。
  10. **「golden 锁不得放进会被重跑覆写的文件」**（`ADR-0028 §3.2`，`F1` 教训的直接外推）—— 凡**纪律位 / 基准值**，一律放**独立、稳定、可 grep** 的文件（如 `docs/refs/denominator-golden.txt`），**不放**进生成器每次整体重写的产物（如 `compat-manifest.json`）。同理：**新增纪律字段前先问「这个文件会被谁重写」**。
  11. **「声明态 ≠ 实物态 ⇒ 纪律位须有外部锚」**（`F1` → `ADR-0028` 链，本班第 4 条指定教训）—— 自声明布尔（`denominator_fixed`）只能证明「**不再改**」，不能证明「**没被剪**」：`F1` 实证三处文档皆记 `true` 而实物 `false`。⇒ `D-3` golden 锁把分母固化成**可证哈希**（外部锚 + 三层机器对撞）：「已完成 / 已冻结 / 已流转」类声明，**凡无外部锚即视为未证明**。实证②：`F7` 曾「`S1-a` ✅ 全闭合」而 manifest 全 `missing`。
  12. **「守卫测不得调用被守卫函数」**（`F20`，`F7` 核可变异 B 实证）—— 卫士若复用**被守卫函数的逻辑**完成校验（`test_verified_entries_cite_real_tests` 调 `promote._test_exists`）⇒ 函数退化（恒真）时**卫士静默空转**（绿、零判别力）。与「读回 = 自证」同族（`F8` / ⑥ 自裁定 ②），**复发在守卫测上**。⇒ **纪律**：卫士须带**已知反例探针**（`assert not check("明显不存在名")`）或**独立实现**；核可方须对**卫士本身**做变异。
  13. **「存在性校验挡不住文本遗迹」**（`F21`，探针 C 实证）—— grep 式「测试名存在性」校验对**注释 / 文档串**中的同名判「存在」⇒ 测试改名后，**旧注释残留**即可骗过「`test_id` 真实存在」断言（假流转弱化版：非凭空编造，指向文本遗迹）。⇒ **纪律**：存在性搜索须**剔除注释行**或要求邻近形态（`#[test]` / `def test_` 行首）。
  14. **「归因叙事也会漂移」**（`F18`，笔 3 核可产出）—— golden 锁死**总数与哈希**，但 **commit / ADR 文案仍写错归因**：实物 `+7 联合类型 / +8 khronos 扩面 / +14 Credentials`，文案却写「+7 / +22」（22 = 14+8 误合）；ADR 缺失清单 7 条 vs 实物新增 15+8。⇒ **纪律**：**机器锁保不了叙事**；回填 ADR / 台账时**按实物逐条数写**（先 diff 前后成员集再落笔），**禁沿用 commit message 文案**；归因与实物不符 ⇒ 同属「声明态 ≠ 实物态」。
  15. **「生成器结转 = 全字段或显式豁免」**（`F19`，探针 E 实证）—— 「保留前序成果」的结转（seed 按 id 结转流转四元组）若**字段清单不全**（漏 `note`）⇒ 带该字段的条目重跑即**静默丢失**（观测量不变）。⇒ **纪律**：结转的字段清单须**显式枚举**；每个被排除字段须**具名理由**，不得默认丢弃。
  16. **「`S0` 时少种」跨族复发（第四例）**（`F22`，`S1-c` 核可产出）—— `F3`（联合类型 7 条）→ `D-S2-1`（Credentials 14 条）→ **`F22`（`storage` 事件面 0 条，设计 §9 表第 9 族明文进分母）**：`4.0`/golden 只防**事后删**，防不住**封口时少种**。⇒ **纪律**：每族开工前先做「**设计进分母清单 ↔ 实物成员集**」对账（一条命令可查）；**缺载体即停报待裁**（补 ⇒ ADR；移出 ⇒ ADR），**禁先实现后补票**（S1c 已现「证据在、清单无」的悬空态）。
