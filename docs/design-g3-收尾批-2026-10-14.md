## §1 目标 / 范围 / 非目标

### 1.1 目标
兑现 **G3 机制债务**：以 stylo **官方 traversal** 取代自建逐元素解析；闭合 **R22/R19①/R23/R24** 具名偏差；补齐 **字体发现**、**执行模型残余**、**Shadow 完整面**、**动态影子**；并对账**引擎域缺口**。

### 1.2 范围（四组）
- **G3X-A 机制收口**：`S1a`（契约硬化）/ `S1b`（driver 采纳 spike）｜`S2`（字体发现）。
- **G3X-B 执行模型**：`S3a` timer / `S3b` 任务化 / `S3c` 宿主 `try_borrow`。
- **G3X-C Shadow 完整面**：`S5a`（P-11 探针）/ `S5b`（`:host`/`::slotted` 级联 + `querySelector` + retargeting + `composedPath` + `slotchange`）｜`S6`（动态影子重排）。
- **G3X-D 质量与对账**：`S7`（值交叉断言 / R22 哨兵追踪 / 覆盖口径 / 教训族 CI）｜`S8`（引擎域 4 项对账）。

### 1.3 非目标（**显名**：⇒ 真 G4 / G5 / G6；**评审 B 指出之章程错位已纠正**）
- **⇒ 真 G4（§18 平台能力闭环）**：存储 / 密码 / 连接 fixture / 图形与媒体契约 / **宿主 CDP 域**。
- **⇒ G5**：全量 manifest / 平台包 / 故障·长跑 / 兼容报告 / **WPT runner（B6）** / **Chromium 差分**。
- **⇒ G6**：**动画·rAF**（原 `G4-S4`）/ **布局扩展**（flex 基本、transform、滚动、table/float、SVG、替换元素、表单；原 `G4-S7`）/ **真实网络（A8）** / **Custom Elements 全生命周期** / 真实 Worker。
- **⇒ G5 内存批**：句柄零泄漏（arena / `self_cell` / `ouroboros`；换型须重走 **R18 硬边界**）。

### 1.4 判据延续（G3 规则不放松）
- **自洽 + 具名偏差**；`capabilities` 不写 `full`；**可推导期望值 + 负对照**（R19 教训，**本批强制**）；
- **收集数下限哨兵**（`COLLECTION_FLOOR=60`，仅升）；
- **教训族**入 CI/脚本（+ 新入 **未回引权威基准**、**全仓扫查勿信选定文件清单**、**接线=调用点存在性**、**禁 `allow(dead_code)` 掩盖 WIP**）：静默丢测 / 锚点补丁回读 / 幽灵 `.so` / 后台命令消除交互提示 / CI 三红案 / 未回引权威基准 / 全仓扫查，勿信选定文件清单（+"举证责任在排除方"配对）/ **接线 = 调用点存在性（不是被调方正确性）** / **禁止 `#[allow(dead_code)]` 掩盖 WIP 未接线**。
