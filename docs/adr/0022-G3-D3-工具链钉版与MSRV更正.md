## 问题

本地开发机 `rustc 1.92.0`、远程验证机 `rustc 1.99.0`，而 `rust-toolchain.toml` 写 `channel = "stable"`。
**已两次因版本漂移导致单端 lint 红**（G1·K-2、G2·D1）。G3 引入大批新代码/依赖，漂移面扩大。
需拍板：是否**钉精确版本**；钉哪个；以及**既存的 MSRV 声明违背**如何处置。

## 讨论要点

| 维度 | 评审 A | 评审 B | 主理人裁决 |
|---|---|---|---|
| 钉精确版本 | 合理（与两次单端红因果判断一致） | 同 | **采纳** |
| 钉哪个版本 | 1.92.0 | — | **采纳 1.92.0** |
| MSRV 论据 | **失实**：`parley 0.11.1` **自身**要 1.88（非 0.12 才 1.88）；`stylo_taffy` 要 1.89.0 + edition 2024 | `stylo_taffy` MSRV 待复核 | **采纳：MSRV 事实更正 + 处置** |
| CI 矩阵收敛 | 须维护者批准 | — | **采纳：仅列「待批条」，`ci.yml` 零改动** |

## 决策

### 决策 1 —— **钉 `channel = "1.92.0"`**

```toml
# rust-toolchain.toml
[toolchain]
channel = "1.92.0"          # 原为 "stable"
profile = "default"
components = ["rustfmt", "clippy"]
targets = []
```

- 依据：`1.92.0` 是**本地现成 + CI 矩阵已有**的版本，改动面最小。
- 远程安装 `rustup toolchain install 1.92.0` 属**用户级安装**（`AGENTS.md` 工具链策略已授权）。

### 决策 2 —— **MSRV 事实更正 + 处置**（**不得以 1.85 假声明继续**）

**亲验事实（主理人 + 架构师复核，原文）**：

| 位置 | 键 | 值 |
|---|---|---|
| 仓 `Cargo.toml:46` | `rust-version` | `"1.85"`（注释`:44` 自认「**意向值**——尚未进 CI 矩阵」） |
| 仓 `Cargo.toml:38` | `edition` | `"2024"` |
| `parley-0.11.1/Cargo.toml:14` | `rust-version` | `"1.88"` |
| `stylo_taffy-0.3.0-beta.2/Cargo.toml:14` | `rust-version` | `"1.89.0"` |
| `stylo_taffy-0.3.0-beta.2/Cargo.toml:13` | `edition` | `"2024"` |
| `stylo-0.20.0/Cargo.toml:13` | `edition` | `"2021"` |

⇒ **新依赖的实际下限是 `1.89.0`**（`stylo_taffy`），**`rust-version = "1.85"` 已被实质违背**
（`parley 0.11.1` 自身即要求 1.88，非 0.12 引入）。**处置（择一，ADOPTED = ①）**：

- **①（采纳）**：把 `rust-version` 更新为**实测下限**（≥ `1.89.0`），或在 **ADR-0005「声明即验证」**
  框架下**标注为「声明即验证、待 `cargo-msrv` 回写」**，并**在 ADR 中显名登记「1.85 违背事实」**。
  最终值由 `cargo-msrv`（若排入）或逐 crate 复核后回写。
- ② 维持 1.85 但**明示「不覆盖新依赖」**（较弱，且与 `edition = "2024"` 的最低要求 1.85 语义混淆）。

> **纪律**：无论择一，**ADR-0022 必须如实登记违背**（不得以 1.85 假声明继续）。

### 决策 3 —— **CI 矩阵收敛 = 待维护者批准条**（不阻塞钉版先行）

- 目标：`["stable","1.92.0"]` → 与钉版一致。
- **铁律 7**：AI **不得修改** `.github/workflows/**` ⇒ **`ci.yml` 在批准前零改动**；
  本条仅作「待批条」记录，**不阻塞**决策 1 的 `rust-toolchain.toml` 先行落地。

## 后果

### 正面
- 消除「本地能编译、远程跑不了」的 lint 漂移（根因 = 版本漂移，非功能缺陷）；
- MSRV 声明与实际一致，避免误导。

### 代价（如实登记）
- 放弃 `stable` 的自动修复；升级须双端回归。
- `rust-version`/`cargo-msrv` 回写待办。
