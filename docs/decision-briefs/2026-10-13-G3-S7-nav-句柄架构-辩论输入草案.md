## 0. 给评审的读法

- 目标：为 stylo 的 `TElement` 句柄 `NodeRef<'a>` 提供**完整导航**（父 / 子 / 兄弟 / 祖先链），**且**满足下方硬边界。
- 若某候选**必然引入本仓 `unsafe`** 或**违反 8B 不变量** ⇒ **直接排除**（不必细评）。
- 产出：**每候选**给「安全可证性 / 维护成本 / 编译可预见性」三维结论 + 排序 + 不选理由。

---

## 1. 一句话问题

stylo 要求元素类型 `E` **恰 8 字节**（单引用），而**可靠导航**（`parent_element`/`traversal_parent`）需要句柄能**回到其所属的节点存储**；但「**slot 持有自身所属 slice 的引用**」是**经典自引用**，**安全 Rust 不可构造** ⇒ 需在**不引入本仓 `unsafe`、不泄漏、不叠加全局态**的前提下，为 8B 单引用句柄找到**可导航**的构造法。

## 2. 硬边界（外部建议必须在内）

| # | 边界 | 依据 |
|---|---|---|
| H1 | **`E` 恰 8 字节**（== `usize`，同 align）；形式 = 单引用 | stylo `SharingCache<E>` 断言 `size/align`（`stylo-0.20.0/sharing/mod.rs:605`）；typeless 占位 `FakeCandidate { _element: usize }`；`ThreadLocalStyleContext::new()` **无条件**构造 ⇒ 违反 panic。对照 blitz `type BlitzNode<'a> = &'a Node`（`blitz-dom/src/stylo.rs:191`） |
| H2 | **父链 `parent_element`/`traversal_parent` 必需、不可 stub**（级联硬依赖） | `TElement::traversal_parent` **必需方法**（`stylo/dom.rs:246`）；`traversal.rs:116` 走链 **`.unwrap()`**（缺父 ⇒ **panic**） |
| H3 | **本仓 `unsafe` 仍封**（R17 冻结面：`layout-backend/src/stylo_host/` 仅 5 个具名 `unsafe fn`） | **ADR-0024** + 门禁 a/b（`crates/runner/tests/workspace_policy.rs`）；新 `unsafe`（含 `unsafe impl`/`unsafe trait`/额外块）= **直接违规** |
| H4 | **零泄漏**（不 leak arena）；**不叠加第二 TLS**（现有 opaque 侧表除外） | 主理人裁决（R18 演进）；**A-1**（一次性 leak + 跨 resolve 复用）已排除；**A-2**（`ouroboros` 直接进本仓/新 `unsafe`）已排除 |
| H5 | **P-4 兼容**：`OpaqueElement` 锚点（`selectors::Element::opaque`）语义不变；Shadow 作用域反查（`implicit_scope_for_sheet_in_shadow_root`）不破 | **ADR-0020 决策 2/3**（P-4 已 PASS） |

## 3. 已被排除的路径（评审无需重走）

| 路径 | 排除理由 |
|---|---|
| **(A) 直译**（slot 持自身 slice 引用） | **经典自引用**，安全 Rust 不可构造 |
| **A-1：一次性 leak + 跨 resolve 复用**（指针寄存器放**既有** opaque TLS） | 每 resolve 的 `&NodeTree` **装不进 `'static`**；且**泄漏**违 H4 |
| **第二 TLS**（新线程局部寄存 tree/slots） | **叠加全局态**（违 H4）；等价于把句柄退化回「不可导航 + 到处查表」 |
| **A-2：新 `unsafe`**（`ouroboros`/裸指针进本仓） | 违 **H3（R17 冻结面）**；`unsafe` 计数膨胀破门禁 b |
| **web-dom 直借（blitz 同构）** | **原文已核**：blitz `Node.tree: *mut NodeTree` + `unsafe { &*self.tree }` + `unsafe impl Send/Sync` ⇒ **依赖本 crate `unsafe`** ⇒ 违 H3（详见 §4·5 / §7·E4） |
| **多字段句柄**（`{tree,id}` 等） | `E>8B` ⇒ 违 H1，**panic** |
| **A-3（当前基线）：导航 stub** | **不满足 H2**（父链必需）⇒ 仅作**过渡**，**非终态** |

## 4. 待评候选（评审逐条给三维结论）

> 请对每项：**安全可证性**（能否给不变量论证、是否本仓零 `unsafe`）/ **维护成本**（依赖 / 类型复杂度 / 借用约束） / **编译可预见性**（是否易被借用检查拒、是否引入 `Pin`/`!Unpin`）三维评估；**并给排序与不选理由**。

1. **`self_cell`**（owner → dependent 的「一格」自引用，安全 API，内部 `unsafe` 属**依赖**）
   - 问：能否把「arena（owner）」+「每节点 slot 持 `&arena`（dependent）」装进 `self_cell`，且**句柄仍是单引用** `&'a ElementSlot<'a>`？其 `'a` 生命周期能否与 `TElement` 的 `Copy` 约束相容？
2. **`ouroboros`**（宏生成自引用结构）
   - 问：是否**只作依赖**（本仓零 `unsafe`）？是否强加 `Pin`/`!Unpin` 而**破坏 `TNode: Copy`**？
3. **`once_cell`/`OnceCell` 帧内背引用**（工程师当前尝试：`SlotCore` 拥有 tree+slots，slot 构造后经 `OnceCell` 回填 `&SlotCore`）
   - 问：**安全构造两阶段**是否可行？**全共享借用**是否被借用检查接受？（**本候选即触发本辩论者**）
4. **受控 arena 变体**
   - 4a. **整树 arena 预先 `Box::leak`**（`'static`）—— 违 H4（泄漏），除非「per-host 有界 + G5 回收」被接受为**L 类优化项**；
   - 4b. **`Rc`/`Arc` 环**（`Rc<RefCell<...>>` 父子互指）—— 问：`E` 是**单引用**还是 `Rc`（`Rc` 亦 8B！）？能否 **`Weak` 打破环**避免泄漏？**但 `Rc` 句柄违反 `Copy`？**（`Rc` 是 `Clone` 非 `Copy` ⇒ **`TNode: Copy` 不满足**）—— 请判定；
   - 4c. **索引句柄 + 树引用寄于 `ElementSlot` 之外的唯一 owner**（如把 `&'a NodeTree` 作为**参数**贯穿 stylo 调用，而非存在 slot）—— 问：stylo 的 `TElement` 方法签名**是否允许携带外部上下文**？（若不允许 ⇒ 排除）。
5. **`web-dom` 直借（blitz 同构）—— ✅ 原文已核 ⇒ **排除****
   - **原文（`blitz-dom-0.3.0-beta.2/src/node/node.rs:91`）**：`pub struct Node { tree: *mut crate::NodeTree, … }`（**裸指针**，注释原文「**This is unsafe!!**」）；
     `:821` `pub fn with(&self, id) -> &Node { self.tree().get(id).unwrap() }` 依赖 `:818` `pub fn tree(&self) -> &NodeTree { unsafe { &*self.tree } }`；
     `:126` `unsafe impl Send for Node {}` / `unsafe impl Sync for Node {}`；`parent_node` = `self.parent.map(|id| self.with(id))`。
   - ⇒ **blitz 导航依赖本 crate `unsafe`（裸指针 deref + Send/Sync）**；本仓 **H3（unsafe 冻结：stylo_host 仅 5 具名 fn + 0 体内块）** 下**不可复刻**。**排除**（除非松动 H3，须明文对称评估）。
6. **其它**（评审可提新候选；须过 H1~H5）。

## 5. 判定标准（三维）

| 维 | 判据 |
|---|---|
| **安全可证** | 本仓**零 `unsafe`**（依赖内 `unsafe` 允许，须注明）；可给清晰不变量；不违反 **H1（8B）**；不违 **H5（P-4/opaque）** |
| **维护成本** | 依赖数 / 类型复杂度 / 借用约束（是否强加 `Pin`/`!Unpin`）/ 与 `Copy` trait 约束相容 |
| **编译可预见性** | 是否**大概率**过借用检查（非「试了才知道」）；是否引入易碎宏 |

**附加约束**：**不得破坏** A-3 已落契约（`ElementSlot<'a> = {tree,id,data,flags,atoms}`，opaque 锚点 = 槽地址）；**违 H1/H3 者直接排除**。
