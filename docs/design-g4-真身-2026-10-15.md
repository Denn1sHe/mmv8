## §6 与 compat-manifest 挂钩

- **schema（G4 扩展 = 「达成层级」，条件①）**：`{ "version": 1, "denominator_fixed": true, "entries": [ { "id", "source", "behaviour", "**level**", "runner", "mode", "evidence" } ] }` —— **`level ∈ {面级, 行为级}`**（**逐条记录达成层级**；**「自洽 + 具名偏差」纪律延伸到清单本身 —— 面级条目不得长得像全量**）。
- **既有机制（G0 已备，见 §6.1）**：`contracts/iv8_contract/manifest.py` = `Entry` / `EntryStatus`（`verified` / `failed` / `missing` / `unknown`）+ **单调性校验** + **成员级 `id` 强制**（**族级名称被显式拒绝**： *"族级名称会让『接口族矩阵』冒充成员级清单"*）。
- **出口门禁**：`missing` / `unknown` **单调下降至 0**（`G4-S6`）。
- **分母固定（§18 条文）**：**不许删测试 / 条目提数**；**分母哨兵**（`4.0`）机器强制（`conftest.py: COLLECTION_FLOOR = 60`，**仅升**）。
- **证据来源**：每条目须可追（**回引 ADR-0025 闸门对齐**）。

## §8 制度 / 冻结（**全部沿用**）

1. **章程回引**：**设计首段回引 §18**（本稿头部已回引；**正文各处再引具体条**）。
2. **判别力 + 负对照**：**每断言含「钉值 + 负对照」**（§4 全表）；**弱门禁不得「通过」**。
3. **教训族**（**六块**）：全仓扫查 / 清单以符号为准 / 批量替换不可信 / 注释·字符串非站点 / 夹具亦须真实性 / 夹具形状须多样；**+ 「静默家族」（跨批次复发：`R19`/片1/`S5b`/`INJ-④②`）**；**验收专项自问「失败时观测量会不会变？」**。
4. **弱门禁防线**：**`missing`/`unknown` 只认 0**；**分母哨兵**（`4.0`）；**逐条目证据可追**。
5. **达成层级纪律（条件①）**：**manifest 逐条记 `level`（面级 / 行为级）**；**面级条目不得呈现为全量**（**「自洽 + 具名偏差」纪律延伸到清单本身**）。
6. **crypto 铁律 6（条件②）**：**`7-2` 只定「契约层级」**；**任何真原语实现 ⇒ 铁律 6 决策上报流程**（**在 G4 步骤内建，不在默认内**）。
7. **冻结流程**：**主理人裁 §7 → 两条独立评审（reviewer-a 证伪 / reviewer-b 从零）→ 冻结**（**冻结后仅显式升版**）。
