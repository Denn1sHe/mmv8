## 0. 总体裁定

1. 两位评审对 **D1~D4 四个方向**的判断与 brief 推荐**全部一致**
   （扁平 arena + `NodeId(u64)`；任务化 + 单线程消息泵；有界推进 + 入队回填 + epoch 作废；显式 target 最小面）。
   **分歧与全部风险在机制 / 签名层** ⇒ 裁定「**方向不变 + 全面机制修正**」。
2. 评审合计 **12 条阻断 / 准阻断项**（A 7 + B 6，去重后并表于 §2）与 **6 条写不出的测试**（§4）——
   全部纳入 **S0 硬门禁**（ADR-0016~0019 + 施工图全面修订）闭合后方可开工 S1+。
3. 两项**实测定形**（P-1a / P-1b，§5）与文档修订**并行**；结论回填 ADR-0017。
4. 对评审建议的**不予采纳项**（如实记录）：cycle 修复不采用 `Box<dyn Error>`（丢类型，取「自持错误 + From」）；
   `Rc<RefCell>` **不做全面扁平化**（取「单锁层级 + copy-out 清单」最小必要修形）。

## 1. 四决策详细裁决

### D1 —— DOM 内核
- **形态**：扁平 arena（`Vec<Option<NodeData>>`）+ 每槽 generation + 不透明 `NodeId(u64)`（打包与 `JsHandle` 一致）。（同 A/B）
- **「不重入」不得停留为纪律（A/B 同判，采纳）**：技术方案 §7 行 189 为**明文要求**
  （「释放 DOM 可变借用后交由 V8 执行」）⇒ 升级为**结构性借用规则**：
  ① **别名单元清单**（`NodeTree` / `NodeMap` / `ListenerRegistry` / `MutationBuffer` / …）——任一单元的可变借用
  **不得跨 V8 回调边界**；② **跨 V8 边界一律 copy-out**（MutationObserver 交付前 `mem::take`；
  `plan_dispatch` 结果为 owned `Vec`；监听器调用前释放全部借用）；③ **单锁层级**定稿 + 专测固化。
- **`NodeMap` 复用存活性（A-B5 = B 断链 11，采纳）**：`wrapper_for` 复用前必须 `resolve` 校验；
  `Collected` ⇒ `unbind` + 新建 wrapper + `bind`；**补 GC 后复用路径测试**。
- **`NodeTree::dispose`（A-B4，采纳）**：最小实现（离树 + 槽释放 + 复用 generation bump），
  使 `nodeid_generation_reuse` 可写（旧 `NodeId` 于新节点必须判失效——专测）。
- **`Rc<RefCell>` 嵌套**：不做全面扁平化；架构师按「单锁层级 + copy-out 清单」定稿（B 残余 #5 最小修形）。

### D2 —— 解析器 + 执行协议 + 调度器
- **执行**：任务化 + 单线程消息泵（同 A/B）。
- **「任务化 ≠ 可中断」（A-B2 = B-3 / 断链 6，采纳）**：脚本任务必须接 **watchdog 截断**（复用 G1 模式）；
  可靠性以 **P-1a** 定形——可 ⇒ `eval_with_deadline` 供 ScriptBlocking / 模块求值任务使用；
  不可 ⇒ **具名登记**（`capabilities` 标志 + 断言该局限的测试）+ 报告主理人。**禁止含糊措辞**。
- **`document.write`**：post-load = **具名错误 `DocumentWriteAfterLoad`**（可判定、可测）；「清空重开」登记 G3+。
  **多条 write 保序**：修正 `pending_writes` 注入序（现 VecDeque + 直注 `push_front` 会**倒置**；
  须保证 call order）＋ 增「多条 write 顺序」回归测试。
- **跨源顺序**：定义确定顺序并测试（源间策略不得留白）。
- **逻辑时钟**：`run_until` 无立即任务时**跳到最近 due 定时器并执行**（虚拟跳转、不 sleep）；
  新增 `logical_clock_fires_timer` 测试。
- **parked-awaiting-IO 任务态（B-9/断链 7，采纳）**：显式建模（出队停泊 + 完成再入队；
  `is_idle` 计入停泊 ⇒ `WaitingIo` 可达）；`WaitingIo` 定义精确化。
- **错误映射（B-8/断链 12）**：`JsError→PageError` **映射表** + `JsErrorKind` 新增变体清单
  （同步 `ALL_KINDS` 穷举守卫）落地；测试可依赖稳定前缀。
- **`NativeFn + Send`（A-B1）**：**P-1b** 定形——去 Send 可行 ⇒ 移除（证据留档）；不可行 ⇒ 侧信道（架构师备稿）。
- **架构细节**：§1.2 补齐全部被引用未定义类型（`Credentials`/`LoadBlockerKind`/`InputKind`/`PageError`/`NetLogEntry`）；
  `PageBinding.writes` 与 `shared.writes` 统一为**单一写缓冲**；seq 图双重借用修复（A-B3）；
  重入双保险（`RunLoop.in_run` + `Realm.in_callback`）集成；脚本任务的错误路径矩阵。

### D3 —— 资源等待 + 导航 + PyO3 控制面
- **形态**：有界推进 + 入队回填 + epoch 作废 + `WaitingIo`（同 A/B）。
- **依赖环（B-1，阻断）**：① `scheduler` 自持错误类型 + `PageError: From<SchedulerError>`；
  ② `NavigationEpoch` 下移共享层（**建议 `policy`**——两依赖边已存在，不引入新 crate）。修后全图无环。
- **导航重绑（B-4，阻断）**：定稿「导航 = **重建 Document/NodeTree + 清 `node_map`/`registry`/`mutations` + 重建 `ParserHost`**」
  过程 + 可观察断言 `stale_document_node_rejected`；**单 Realm 下旧 JS 全局残留 = 具名登记偏差**
  （Realm 级替换属 G4）。
- **`res/rej` 表归宿（B-6）**：定稿为 `Rc<RefCell<FetchTable>>`（由 `PageShared` 持有、`__iv8_fetch` 闭包 clone 捕获；
  受 P-1b 制约）。
- **epoch 覆盖面**：`timer`/`input` 任务同挂代次（不只 network）；`TaskToken` 携带方式定稿。
- **fetch 两条 resolve 路径**（OfflineBundle 同步命中 × `complete` 任务回填）在 ADR 写明并测试。
- **ADR-0014 覆盖扩展（A-B7）**：G2 新增 PyO3 入口全部纳入 RAII 重入纪律（`try_borrow_mut` 形态）；
  以 ADR-0014 修正注记 + ADR-0018 记录。
- **A 的 URL 规范化修正**（query/fragment/default-port/case + 端口断言）并入。

### D4 —— 输入最小模型
- **形态**：显式 target 可信事件；命中测试推 G3；`capabilities.input="explicit_target"`（同 A/B）。
- **JS `Event` 对象桥（B-9/断链 9，阻断→补齐）**：构造 + 每步 `currentTarget` 更新 + `type`/`isTrusted` +
  `preventDefault`/`stopPropagation` 回读；两条测试转为可写。
- **分派期监听器变更**：移除尚未调用的监听器**须跳过**（调用时检查）；同 target 分派期间新增**不参与本次**；
  `add` 去重（同 type+callback+capture）、`remove` 匹配 capture——按规范语义定稿 + 测试。
- **`el.click()` 与重入禁令（A/B 同判冲突）**：裁决 = **区分两种重入**——
  「宿主回调内再次**求值脚本**（`eval`/`eval_module`）」**维持禁令**；
  「分派期**调用监听器**（`call`）」为语义必需，由**专用路径**放开（engine-v8 设计具体形态 +
  SAFETY/深度论证）⇒ **ADR-0014 修正注记 + ADR-0019 记录**。
- **`activeElement` 最小态纳入**（click⇒焦点可观察）；`sticky`/`transient` 保持最小口径。

## 3. 模块脚本纳入裁决（K-11 消解后）

**裁决：纳入 G2 最小面**。约束（A §8 + B §7 合并）：

1. **暂停点对 `type` 无感** ⇒ 驱动在暂停点分流：classic ⇒ `ScriptBlocking` 任务；
   module ⇒ **defer 队列**（独立于 ScriptBlocking），**永不在暂停点执行**；
2. 执行点 = **解析完成后、`DOMContentLoaded` 之前**；**三条顺序回归测试**（与 classic / defer 的相对序）；
3. **整图必须可同步解析**（OfflineBundle 同步查表）；未命中 = **可判定失败**（**绝不静默挂起**）；
   `module_resolver` 的 `None` 语义与解析失败区分（**ADR-0015 空返回纪律覆盖**）；
4. **TLA 在 G2 显式报错**（具名）；
5. 模块求值任务同样受 **watchdog** 覆盖（P-1a）；
6. `import.meta` base URL：内联合成 URL 口径登记；
7. 失败必须**可在 `run_until` 观测**，不得静默跳过；「模块 ≠ load-blocker（defer、不阻塞解析）」关系写清。

## 5. 探针清单（P）

- **P-1a**（决定 ADR-0017 watchdog 节）：watchdog + `terminate_execution` 对 **`eval` 内纯计算死循环**
  的截断可靠性（含恢复与错误形态记录）。不可靠 ⇒ 立即停手、如实记录。
- **P-1b**（决定 ADR-0017 NativeFn 节）：`NativeFn` 去 `+ Send` 可行性（编译/测试/clippy 全绿 + 无 Send 需求证据；
  出现反例 ⇒ 回退并留证）。
- **P-2**：S8 首步**全栈暂停点回归确认**（U-1 源码链已成立，保持回归价值）。
- **P-3**：多条 `document.write` 顺序（设计修正 + 测试即可，无需独立探针）。
