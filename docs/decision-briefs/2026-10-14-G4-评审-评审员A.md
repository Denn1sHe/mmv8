# G4 设计批 · 独立评审 A（**证伪视角**）—— 2026-10-14

> 只读仓内 + 本地 registry 源级取证；不改码。对象：`docs/design-g4-2026-10-14.md`、输入清单、G3 §6/§7。

**结论：有条件支持。** 范围划分与台账映射基本成立；**但 R22 靶心很可能错**（白付 vendor 补丁成本）、**P0 三件按现粒度均不可完成**、矩阵**多处弱观测**、出口**缺 2 前置**。建议：**先修 R22 靶心 + 拆 S1/S3/S5 再冻结。**

## A.【主挑战】R22 靶心 = 本仓 `TShadowRoot::style_data()`，**不是**上游 `implicit_scope_root`

- **证据**：`:host` 匹配只读 `MatchingContext.shadow_host()`（`selectors-0.40.0/matching.rs:1068-1074`）；host 由 **`TElement::each_applicable_non_document_style_rule_data`** 默认实现给出——`stylo/dom.rs:840-864`：`containing_shadow_ignoring_svg_use` → **`if let Some(data) = shadow.style_data() { f(data, shadow.host()) }`（`:855-856`、`:860-862`）** ⇒ 影子树作者规则与 host **全经 `style_data()` 注入**。
- **本仓实况**：`stylo_host/dom.rs:77-83` `style_data() -> Option<&CascadeData> { None }`（注释「留待 S11」）⇒ **通道被我们自己关死**，与 `implicit_scope_root` 无关。
- **零补丁可达**：`CascadeData::new()` pub（`stylist.rs:3419`）+ `DocumentStylesheetSet::new/append_stylesheet/flush()` pub（`stylesheet_set.rs:457/350/505`）+ `flush_origin()` pub（`:91`）+ `CascadeData::rebuild(..., SheetCollectionFlusher, ...)` pub（`stylist.rs:3456`）⇒ **仅公开 API 即可为每个影子根自建 `CascadeData`**。
- **`implicit_scope_root` 是另一件事**：只在 `CssRule::Scope` 分支消费（`stylist.rs:4347-4376`），服务 `@scope`/`:scope`（`selectors .../matching.rs:1309-1323`）；gecko 参考实现在 `gecko/data.rs:128-152`。**它不是 `:host`/`::slotted` 的通道。**
- **建议**：**先零补丁探针**（`style_data()` 返回自建 `CascadeData` → 跑 `host_selector_styles_host`/`slotted_...`）。命中则 R22 的 **vendor 补丁+长期维护成本整体归零**，并消掉「§6 新增依赖=无」与「vendor fork」的自相矛盾；未命中再谈补丁。**补丁形态（若终需）**：`stylesheet.rs` `DocumentStyleSheet`（`:289`）加 `shadow_scope_root: Option<OpaqueElement>`（**该结构 derive `MallocSizeOf` 而 `OpaqueElement` 未实现 ⇒ 须 `#[ignore_malloc_size_of]`**）+ `implicit_scope_root`（`:311`）返 `Some(ShadowHost(..))` + setter；≈20–30 行，但**元组构造断裂** ⇒ 本仓构造点同步 + **每次 stylo 升级重放**。

## B. P0 三件工作量（**均低估**）

- **S1「统一走 traversal」= 大手术**：driver 需 `store_children_to_process`/`did_process_child` **语义正确且原子**（本仓 `dom.rs:296` 现为桩 `-> 0`）、`damage/hint` 全生命周期、`TraversalFlags`+LAYOUT 态+Sequential 队列；且 `ElementSlot` 是 **per-`build_slots` 泄漏**（R18 as-built）而 driver 假定**跨 traversal 持久** ⇒ **与 leak 模型/`reset()` 冲突**。**拆 S1a（契约硬化：`style_data()`/bloom/写回回归）/ S1b（driver 采纳，spike）**。
- **S3「执行模型收口」= 加载路径重构**：timer+脚本任务化+宿主 `try_borrow`（5 路径）触 **铁律 6 ⇒ 须先 ADR**；改 `page.rs`/`parser.rs` 主链，回归面 ≥ G2。**拆 S3a timer / S3b 任务化 / S3c 宿主 borrow**。
- **S5 与 §1.3 自相矛盾（阻断级）**：S5 含 **Custom Elements**，§1.3 却把「Custom Elements **全生命周期**」列 **G6**；**G4 做哪个子集未定义 ⇒ 无法验收**。且 S5 塞 `:host`/`::slotted`+`querySelector`+retargeting+`composedPath`+`slotchange`，**疑 5+ 步塞 1 步**；附表标 **`P0/P1`** 而出口要「P0 全绿」⇒ **是否出口必需未定**。

## C. 矩阵弱观测（「实现错了它会红吗？」）

- **弱**：`multi_element_invalidation_cleanup`（仅「非旧值」未钉值——**R19 的 514 教训**）；`system_font_discovery_cjk`（`>0` + 系统字体 ⇒ **与「本地稳定」冲突**，应钉 **fallback 家族名**）；`timer_task_queue_runs`（未钉「第 N 轮/不阻塞 load」，**同步实现也能"按序"过**）；`raf_frame_drives_restyle`（未钉帧数/几何值，rAF 语义未定义）；`dynamic_shadow_relayout`（**「非空」≠ 正确**）；`event_retargeting`/`slotchange_fires`（未钉 `target` 具体节点/触发次数）。
- **中**：`unified_traversal_elementdata_lifecycle`（三不变量一条、无负向对照 ⇒ 互相掩盖，宜拆+反向注入）；`flex_basic_layout`/`transform_geometry`/`scroll_metrics`（「规范值」**未给来源与容差**）。
- **强**：`host_selector_styles_host`/`slotted_...`（**有具体值**：`:host` 宽 120）✓；`collection_floor_sentinel` ✓。
- **不可执行（阻断）**：`cdp_subset_diff`——T1.3 至今只有 `NullDifferentialBackend`（`contracts/iv8_contract/differential.py:128`、`:16`「不接触任何浏览器」、`:251`「(未接入)」）⇒ **「骨架复用」不足**，S9 须**新增子步骤「接入真实 Chromium backend」**，否则 §4.9 恒假。

## D. 出口条件（§5）+ 遗漏（合并）

1. 缺 **R22 通道结论**（patch vs 自建）⇒ S5 无前置无法验收；2. 缺 **CDP 真实后端**子步骤；3. 「§4 矩阵通过」未附 **G3 §3 的「可推导期望值」规则** ⇒ 弱观测可"通过"（假绿）；4. 无**性能/增量**出口（R15 全量 restyle 已登记却不设界）；5. 缺 **导航后 `reset()` 的 ElementData/CascadeData 生命周期**回归（S1 持久化必触）；6. S5 的 P0/P1 歧义。
7. **O1** `reset()`（D8/R6）须扩展清 `CascadeData`/影子数据——未提；**O2** **A7 系统字体 vs「本地口径」冲突**（R4 容差 vs 本地稳定）⇒ 须先定「本地断言只用内嵌字体，系统字体仅真实页」；**O3** **S4 后 R21 预警的 3 处文档锁路径**（`matching.rs:567/650`、`animation.rs:236/1694/1700`）**无判别性测试** ⇒ 补「非空动画 ⇒ 不命中 `read_with` 断言」；**O4** **§6「新增依赖=无」与「R22 vendor fork」互斥**（供应链/SBOM 面）；**O5** **S9 要改 `.github/workflows/ci.yml`（铁律 7）⇒ 须维护者批准**，未标审批项；**O6** `COLLECTION_FLOOR`（仅升）与「覆盖不回落阈值」（软）交互未定；**O7** S7 批次未进矩阵（`transform/scroll` 与 flex 同列、无批次列）⇒ 出口不清。
