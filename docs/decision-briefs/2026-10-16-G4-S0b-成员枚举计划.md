## §1 成员 id 规范（与既有门禁对齐）

- **形式**：**`<Interface>.<member>`**（**含点**，成员级）；沿用 `manifest.py` 既有强制（`"." in id`）。
- **成员语义（WebIDL）**：**属性 / 方法 / 常量 / 事件**（四类；事件按 `on<name>` 记为接口成员）。
- **族级名字禁用**：`"Window"`（无点）⇒ 既有门禁**当场拒**。
- **跨族接口**（如 `SVGAnimatedLength.baseVal`）同规则：`Interface.member`。

## §2 候选源 A（**首选**）：社区 `v0.1.4` 实物自省枚举

**前提**：维护者提供实物位置（**主理人已在确认**；本仓 `poc/` = 我方 spike，**非**社区实物）。

**枚举（两腿，取并集，来源逐条可追）**：

```bash
# A-1 Python 面：模块 + JSContext + 导出名（可复现）
python3 - <<'PY'
import iv8, inspect, json
out = {"members": [], "source": "community-v0.1.4:python-introspect", "method": "inspect"}
ctx = iv8.JSContext                       # 社区版主入口
for name, member in inspect.getmembers(ctx.__class__):
    if name.startswith("_"):
        continue
    kind = "method" if callable(member) else "attribute"
    out["members"].append(f"iv8.JSContext.{name}")
print(json.dumps(out, ensure_ascii=False, indent=2))
PY

# A-2 JS 面：全局 + 各构造器原型成员（可复现）
#   经 iv8 的 eval 通道自省（不依赖浏览器）：
python3 - <<'PY'
import iv8, json
ctx = iv8.JSContext()
probe = r'''
(function () {
  const out = [];
  const ifaces = Object.getOwnPropertyNames(globalThis)
      .filter(n => typeof globalThis[n] === 'function');
  for (const n of ifaces) {
    for (const m of Object.getOwnPropertyNames(globalThis[n])) {
      if (!m.startsWith('_')) out.push(n + '.' + m);
    }
    const proto = globalThis[n].prototype;
    if (proto) for (const m of Object.getOwnPropertyNames(proto)) {
      if (m !== 'constructor') out.push(n + '.' + m);
    }
  }
  return JSON.stringify(out);
})()
'''
print(json.dumps({"members": json.loads(ctx.eval(probe)),
                  "source": "community-v0.1.4:js-introspect"}, indent=2))
PY
```

**产出**：`contracts/community-v0.1.4-members.json`（格式见 §4）。
**可追性**：`source` + `method` 字段记录**来源与命令**；`test_ids` 由 `cases/` 双模式探针补齐（`R-3`：探针 = **证据来源**，非定义源）。

## §3 候选源 B（**兜底**）：规范面（WebIDL）枚举

**触发条件**：维护者**无可枚举实物**。

**范围收窄（**关键**）**：只对 `§11/§12` **已具名的接口族**枚举，**不外扩**（防分母无界）：

| 族（提取件已具名） | 候选接口（示例，**非穷举**） |
|---|---|
| 存储 | `Storage` / `StorageManager` / `StorageBucketManager` / `IDBFactory` / `IDBDatabase` / `IDBTransaction` / `IDBObjectStore` / `IDBIndex` / `IDBCursor` / `IDBRequest` / `CacheStorage` / `Cache` / `CookieStore` |
| 密码 | `Crypto` / `SubtleCrypto` / `CryptoKey` / `Algorithm` 系 |
| 图形媒体 | `CanvasRenderingContext2D` / `OffscreenCanvas` / `WebGLRenderingContext` / `WebGL2RenderingContext` / `WebGPU` 系 / `AudioContext` / `AudioNode` / `HTMLMediaElement` / `MediaStream` / `WebSocket` / `RTCPeerConnection` 系 |
| 编码文件 | `TextEncoder` / `TextDecoder` / `Blob` / `File` / `FileReader` / `URL` |
| 设备 | `Geolocation` / `Notification` / `Clipboard` |
| 宿主 CDP（`§13`） | 域 × method/event（`Runtime.*` / `Debugger.*` / `DOM.*` / `CSS.*` / `Network.*` / `Page.*` / `Storage.*` / `DOMStorage.*` / `IndexedDB.*` / `Target.*`） |

**枚举命令（可复现）**：以 **WebIDL 文本**为输入，逐接口抽成员（属性/方法/常量）——

```bash
# B-1：从 WebIDL 片段抽成员（示例：IDBFactory）——纯文本、无外部依赖
python3 - <<'PY'
import re, json
idl = open("refs/webidl/indexeddb.idl", encoding="utf-8").read()  # 输入：规范 IDL 片段
iface = "IDBFactory"
body = re.search(rf"interface\s+{iface}\s*\{{(.*?)\}}", idl, re.S).group(1)
members = re.findall(r"(?:readonly\s+)?attribute\s+[\w<>?]+\s+(\w+)", body)
members += re.findall(r"[\w<>?]+\s+(\w+)\s*\(", body)
print(json.dumps(sorted({f"{iface}.{m}" for m in members}), ensure_ascii=False, indent=2))
PY
```

**产出**：同 §4，但 **`source` 显名「spec-webidl」+ 必带 `"needs_community_review": true`**
（`§14` 口径：**待社区实物复核**；`R-3`：规范面 **非**定义源 ⇒ **须显名**）。

## §4 产出格式（`load_members` 认可）

```json
{
  "members": ["IDBFactory.open", "IDBFactory.deleteDatabase", "..."],
  "source": "community-v0.1.4:js-introspect | spec-webidl",
  "method": "<产生本文件的命令，逐字可复现>",
  "extracted_at": "2026-10-16",
  "needs_community_review": false
}
```

- **`members` 非空**（`load_members` **fail-closed**：空数组/缺文件 ⇒ 红）；
- 额外键**被容忍**（`load_members` 只读 `members`）⇒ `source`/`method` **可随文件入库**（**可追性**）；
- **落位**：`contracts/community-v0.1.4-members.json`（与 `compat-manifest.json` 同目录）。
