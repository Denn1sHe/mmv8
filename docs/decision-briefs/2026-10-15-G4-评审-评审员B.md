> 推导源：docx §18 章程 + §11/§13/§14/§15 逐域原文；`contracts/iv8_contract/manifest.py`（四状态/成员级/单调性）；`contracts/cases/`；`docs/g3x-收官尾账-2026-10-15.md`（静默家族）；`ADR-0025`。

## ① 从零推导：**真正**清零 community `missing`/`unknown` 的三个必要条件
- **N1 分母外部锚定**：`missing/unknown=0` 的语义 ="**社区版 v0.1.4 公开接口清单**里没有未达成员"。此清单是 **§18 G0 的必须产出**（"社区版接口清单"）。若分母由本批自行枚举 ⇒ 「0」只证明"我们列的条目都过了"= **剪刀**。
- **N2 成员级 + 未达显名**：`manifest.py:88-93` 已**强制** `.`-形式成员级 id（拒族级）；故**任何未实现的成员必须以 `missing` 出现**，而不是"不在清单里"。
- **N3 层级只是标注**：`level ∈ {面级,行为级}` 只能**诚实标注**该条目测到哪一层；**不得**用一条 `面级` 条目**顶替**其下属若干成员的 `missing`（否则即改名游戏）。

## ③ ③「宿主 CDP 域 = 宿主实际暴露域子集」的从零复核
- 章程的**合法性来源**是能力目标：§13 原文要求宿主提供 `DOM/CSS/DOMDebugger/Network/Page/Storage/DOMStorage/IndexedDB/Target` **等所需域** + **公布已支持 method/event 清单**，且「**Elements/Application 面板由这些域共同支撑**」。
- 7-5(b) 的判据「以 manifest 条目为准 + 域握手/命令事件可验收为限」是**自证闭环**：可以缩到"`Runtime.enable` 握手即通过" ⇒ **子集会小到失去意义**（正落「静默家族」）。**必须外部锚定**。
- **建议最小可用集**（行为级判据）：`DOM.getDocument`/`DOM.querySelectorAll`/`DOM.getOuterHTML`（Elements 树）+ `CSS.getMatchedStylesForNode`（样式）+ `Page.navigate`/`Page.loadEventFired` + `Storage`/`IndexedDB` 列举（Application）；**负对照**：撤域注册 / 撤 `NodeId↔nodeId` 映射 ⇒ 红。并把「**已支持 method/event 清单**」作为 M5 的**交付物**（非仅握手）。

## ④ 面级/行为级封顶：诚实封顶 or 改名游戏？（判据）
- **诚实封顶**（v2 已具备）：① §18 对这五域里 M3/M4 本就要的是 **fixture/契约**（非全实现）⇒ 占位**忠实**；② `level` 逐条 + 「面级不得呈现为全量」（§8-5）+ `capabilities` 不写 full。
- **仍是剪刀的残余**：`denominator_fixed:true` 是**自声明布尔**（`manifest.py` 现无该字段、无外部锚）⇒ 只能证明"不再改分母"，**不能证明分母正确**。4.0「删条目 ⇒ 红」只防**事后删**，不防 **S0 时少种**。
- **⇒ 须补（可判定的两条）**：**(i) 分母 = 社区清单成员集**（成员级、且**未达成员显名 `missing`**）；**(ii) 覆盖率不变量**：社区清单中的每个成员 id 必在 manifest（`清单 ⊆ manifest`）+ manifest 无清单外杜撰 id（双向核）。缺此两条，`G4-S6 = 0` 不可证伪。

## ⑤ 需重开的裁定
1. **7-2（M2「密码」）＝ 最高优先重开**：§18 未定义「密码」；docx **§11 的 WebCrypto**（算法/密钥/摘要/加解密/签名/派生/getRandomValues）与 **§15「安全与权限｜policy/bindings｜Permissions、Credentials…」** 是**两个家族**。v2 取 **Credential Management**，且 `4.2b` 把 crypto 真原语整体推后 ⇒ **crypto 家族可能整个缺席分母**。**裁定项**：「密码」= WebCrypto 还是 Credentials？若是 WebCrypto ⇒ 至少补**面级**（`getRandomValues` + 算法名 + `CryptoKey` 槽 + `subtle` 面），真原语推迟才成立；若是 Credentials ⇒ 须**显名**把 WebCrypto 移出分母（ADR 记录）。
2. **7-5（CDP 子集）**：补外部锚（见 §③）。
3. **7-1（IDB 面级）**：补"未达成员在分母中的记法"（显名 `missing` 或经 ADR 移出分母）—— 否则 G4-S6 是剪刀。
4. **7-6（基线来源）**：把"**外部锚定**"写成硬约束；`cases` 双模式实测只能作**证据来源**，不能作**分母定义源**。§6.1 自陈「G0 冻结清单不达」= **G0 欠账**，应在 M0 显名登记（v2 方向对，缺显名）。
5. **§18 语义重定义须写明**：章程里「清零」是 G4 **通过后开展**；v2 把它定为 **G4 出口（G4-S6）**⇒**加严**，可接受，但须落 ADR 说明（否则 G5「全量 manifest 通过」与之重复/同义反复）。
6. **同意**：7-3（Native 接口入 G4、真传输 ⇒ G6）、7-4（契约层 + 行为级别）、7-7（`box_tree` 扁平化 ⇒ G6 + G4 显名）、7-8（字体归 M4）；ADR-0025 §3.3 对 A8/S7/S4 的自我纠正**正确**。

## ⑥ 结论
- v2 = **方向正确的诚实草案**（五域全落、教训族/负对照/哨兵制度齐全）；**不构成改名游戏**的条件已大半具备。
- **剩两处决定成败**：**「密码」所指（7-2）** 与 **「分母外部锚定 + 覆盖率不变量」（4.0/N1/N2）**。此二项不闭合，`missing/unknown=0` 不可证伪 ⇒ 仍可能是剪刀。
- 另需处理 §② 表内标 ❌/⚠️ 的家族（编码文件·URL / Streams / 安全与权限 / 设备通信 / Worker 社区版契约 / WebGL·WebGPU·SVG / CacheStorage·Storage Buckets / Web Audio·MediaStream、WebRTC·WebCodecs / storage 事件）。它们**可**经 ADR 显式移出分母，但**不能**默默不在清单里。
